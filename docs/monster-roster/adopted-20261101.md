# モンスター一覧・まとめて変換（採用仕様の実装）

元仕様: https://docs.google.com/document/d/1vArS4e48D6VhCP20PccSELhvKFQOA03FN1XGb-iGw5M/edit

開発ベース: `2b89e64cb19c81bdc9b60e86931f4aa3f5110db9`。
ユーザーが実装前報告の報酬表とUID保護方針を承認。本編マージ・公開は未承認。
ホーム・世界地図・ガチャの採用改修はベースmainに含まれる。共通ヘッダー・ナビを再利用し、新しい競合があればマージ順を確認する。

## 実装

- 5列の正方形アイコン。顔が見える上寄せ表示、レア度枠、Lv/★、ロック・編成・遠征の印。画像は遅延読込。
- 通常サイズでは一覧部分のみスクロール。上下の操作は固定。高さ340px以下の極端に低い分割・拡大表示では、操作部に到達できるよう外枠もスクロール可能にする。まとめて変換中は下部ナビを隠す。
- 種類・★・重複で絞り込み、入手新/古・★・Lv・図鑑番号で並び替え。端末内にプロフィール別保存（ゲームセーブには新項目を加えない）。
- 詳細シートに技変更・データ使用・ロック・単体変換、所持数、EXP、錬成補正を移設。
- 一括選択は表示中の選択可能個体に限定。重複選択では同一IDのLv最高、同Lvなら既存配列で最古の1体を残す。
- 確認シートは1回。報酬合計、最後の同種、Lv20以上/★3以上の注意を表示。手持ち0体は無効。
- モンスターとキャラクターは別報酬表。レベル比例・育成費払い戻しはなし。

## 保存・参照の保護

確定直前に全UIDを再検査する。重複UID・存在しないUID・保護個体を含むバッチは何も消費しない。確認時のプロフィールとセーブ全体が変わっていた場合は再確認を要求する。

保護対象はロック、編成、遠征（報酬未受取を含む）、未完了チュートリアルの必要個体、選択中の錬成触媒、錬成実行中、進化待ち、進行中戦闘、物語戦の再開対象、戦闘結果保存待ち、契約処理中。

`captureSaveTransaction()`で控えを作り、個体・装備参照の削除、報酬・アイテム図鑑への反映、お気に入りの残存個体への切替をまとめ、`saveGame({requireReadable:true})`を1回だけ呼ぶ。失敗時は`rollbackSaveTransaction()`で復旧する。成功後だけ、技編集UIDと未派遣遠征選択から削除UIDを外す。所持技カード、入手済み図鑑、既存ID、セーブキー`mb_v95c`は維持する。

技合成は既存の所持/装備/UID署名で古いプレビューを拒否する。ガチャ獲得記録は履歴として保持し、変換によって個体を再生成しない。

## 既存検査とチュートリアル

旧カード・折りたたみ・上部編成ボタンの検査を、アイコン・詳細シート・下部編成ボタンへ更新。保存済みチュートリアルのステップIDは維持する。エルナのアイコンを案内し、`growth_skill_open`再開時は該当個体の詳細を開く。絞り込みで案内対象を隠さない。技変更の実ボタンをハイライトする。

## 検証コマンド

- `npm run check`（全体検査。通知、データ、保存、UI、チュートリアル、バランス検査を含む）
- `npm run check:character-recycle`（従来変換と新しいバッチ取引の保護・報酬・一括保存・巻き戻し）
- `npm run check:monster-roster-browser`（360/412/1366px、プロフィール1/2、実ブラウザで操作・保存・再読込・容量不足・別タブ更新の保護）
- `node scripts/test-individual-evolution-browser.mjs`（詳細からのデータ使用、実際の進化、保存・再読込）
- `node scripts/test-tutorial-evolved-companions.cjs`（進化済み個体、保存済みステップからの再開、実ボタンでの案内進行）

ブラウザ検査はChromiumの画面サイズ再現であり、Galaxy/Android実機検証の代わりではない。

## Galaxy実機で確認すること

1. 縦画面で5列、横にはみ出さず一覧だけスクロールする。画像・Lv・印が読める。
2. 絞り込みチップを横へ動かせ、並び順が再訪・再読込後も残る。
3. 詳細を開き、技変更・データ使用・ロック・閉じるが押せる。長い詳細を最後までスクロールできる。
4. まとめて変換で、保護個体に理由が出て選択できない。重複選択でLv最高の1体が残る。
5. 確認は1回だけで、報酬と注意が読める。「戻る」では減らず、確定後は合計どおり増える。
6. 再読込後も結果が残り、編成・遠征・ホームのお気に入り・錬成に異常がない。
7. 序章のエルナ育成案内がアイコン→詳細→技変更と進む。再開でもボタンが隠れない。

実機で意図的に容量不足を起こす必要はない。容量不足と別タブ競合は使い捨てプロフィールによる自動検査で扱う。
