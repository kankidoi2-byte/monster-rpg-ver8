# UI再設計：共通デザインシステム

この文書は、新UIへ移行する全画面で共有する最小デザインルールを定義する。実装値は`prototypes/ui-redesign/style.css`のカスタムプロパティを基準とする。

## 体験を表す言葉

- 明るい
- 王道ファンタジー
- 冒険へ出たくなる
- モンスターが主役
- 一目で分かる
- 短く強い反応

## 色

### 基本色

- 背景：空色から暖かい白への明るいグラデーション
- 紙面・カード：わずかに黄みを含む白
- 主要操作：鮮やかな水色から青
- 強調・報酬：金色
- 成功・HP：緑
- 危険・敗北・高難度：赤
- 本文：濃い青灰
- 補助文：中間の青灰

### 属性色

属性色は技、属性バッジ、短い縁取りへ使用する。広い背景全面を属性色で塗らず、モンスター画像と本文の読みやすさを守る。

## 文字

- 本文と操作：端末標準のゴシック体
- 大見出しと冒険名：読みやすい明朝体を候補とする
- 最小本文：12px相当を下回らない
- 補助情報：10px相当まで使用可能だが、主要判断を補助情報だけに置かない
- 数字、HP、報酬：周辺の本文より太くする

## 余白と形

- 基本余白：4px刻み
- 画面左右：16px
- 主要カード内：14〜18px
- 小カード角丸：12px
- 通常カード角丸：18px
- 主役カード、マップ画像：26px
- タップ領域：原則44px以上

## 共通部品

### 常設ナビゲーション

- 5項目まで
- 画面下部に固定
- バトルを中央で最も大きくする
- アイコンと短い名称を併記する
- 現在地を色と背景の両方で示す

### 主要ボタン

- 青のグラデーションと白文字
- 一画面に同格の主要ボタンを複数置かない
- 押下時に即座に縮小または沈み込みを返す
- 無効状態は彩度、コントラスト、操作可否のすべてで区別する

### カード

- 画像を先に見せ、枠線と影は控えめにする
- タイトル、重要状態、次の操作だけを初期表示する
- 詳細文、倍率、長い説明は展開表示へ移す
- 選択中、おすすめ、遠征中、進化可能などは短いバッジで示す

### HP・進捗

- 現在値と最大値を併記する
- 主要バーは10px以上の高さを確保する
- HP低下時は色だけでなく、形または警告表示も変える
- 戦闘ダメージでは、即時値と遅れて追従する演出値を検討する

## 状態表現

- 通常：白または明るい青
- 選択中：青の縁取りと淡い背景
- おすすめ：金色の縁取りと短いラベル
- 成功：緑と上向きの動き
- 警告：橙と明確な短文
- 危険・失敗：赤。常用せず重要場面に限定する
- 無効：低彩度に加え、理由を確認できる状態にする

## 動き

- ボタン反応：100ms前後
- 通常攻撃：1秒前後
- 強力な技：2〜3秒以内
- 画面遷移：200〜300ms
- 報酬加算：複数の成果を短い間隔で連続表示
- `prefers-reduced-motion`では移動、点滅、画面揺れを抑える

## 画面幅

- 基準：スマートフォン縦画面
- ゲーム操作領域：最大430px前後を基準に検証
- PC・Chromebook：中央へゲーム領域を置き、必要に応じて左右へ補助情報を展開
- 横画面：破綻させないが、横画面専用操作は作らない

## アイコン

- 最終的には統一されたゲーム用アイコンへ移行する
- 改修途中は、意味が明確な既存記号を一時利用できる
- アイコンだけに意味を持たせず、主要ナビゲーションでは短い文字を併記する
- 色だけで状態や属性を判別させない
