## 実装

- 一覧専用 `skillDexCardMarkup` で名前→COST→属性→性能→分類・全文説明→詳細リンク風ラベルの順序。単一のネイティブ button なので全体をタップ/Enter/Spaceで操作できる。
- 一覧限定 `#skillDexList` セレクター。全面に濃い属性色と明るい属性色の枠。既存ゲームの10属性色相に合わせ、単属性は均一色、複属性は全体を50%の鋭い斜線で分割する。
- 白文字、黒COSTバッジ。旧紺色の属性/威力帯を除去。新規画像・大型装飾なし。
- 2:3は推奨比率で、説明量に応じ高さが伸びる。固定高・省略・クリップなし。同一行は高さを揃え、詳細表示ラベルは下端。
- 320–430px は2列、横画面/PCは可読最小幅から列数を調整。rem単位の最小幅で文字拡大に合わせて1列へ再配置できる。
- キャッシュキー更新と `AGENTS.md` 必須のお知らせを追加。
- 技データ・性能・取得条件・ID・セーブに変更なし。
