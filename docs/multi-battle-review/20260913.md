- `npm run check`（postcheck含む）成功。初回は既存のキャッシュ識別子を置換したため旧識別子契約チェックが失敗。既存識別子を保持して追記する方式へ直し、検査基準を変えず成功。
- `npm run check:world-map-economy` 成功。既存勝利・報酬・契約処理の一致を確認。
- `test-multi-battle-motion-update.mjs`: 基準mainで被弾クラス保持のassertが失敗し、修正版で成功。被弾・詠唱クラスと移動座標を保持。
- `test-multi-battle-outcomes.mjs`: 3方向（味方→敵、敵→味方、敵→敵）×14効果＝42条件で、最新mainとHP・状態・敵レコード・コイン・ターン・乱数呼出し回数が一致。
- 既存readabilityテストの13条件の通常戦計算比較も成功。
- 実Chrome・隔離iframe: 既存14項目成功。新規15項目成功（被弾直後／連続更新／自然終了、画像・HPバー・残像ノード保持、敵同士の連撃2発と陣営表示、敵の上限回復、防御・盾・障壁の消費、毒撃破の契約帰属、撃破後の選択除外と再解決、乱入前後のHP・状態・ターン・履歴・次の入力）。
- UI操作で火炎牙→敵Bをタップ→味方攻撃→敵B防御→敵A攻撃→次のコマンド入力を確認。履歴の対象とHP変化が対応。
- 三つ巴を320/360/412/844px設定で確認。iframeの内寸高さは外寸より4px小さい。横溢れ・HPへの操作欄遮蔽なし。通常コマンド最小高さ44px、中央66px。乱入を360px縦／844px横でも確認。
- 小画面・多状態・技／対象選択中は縦スクロールが必要。全要素が常に1画面に収まるとは主張しない。
