# ココロリンク Phase 3：実戦発動とバトルUI

状態：実装完了  
対象：発動UI、効果適用、通常戦・三つ巴戦・乱入戦  
プレイヤー向け挙動：利用可能

## 1. 実装したプレイヤー操作

バトル画面の補助コマンドへ「💞 リンク」を追加した。開くと、現在戦闘中ではない控えモンスターと、発動時に得られる効果量を確認できる。

- 障壁量
- 攻撃上昇率
- 素早さ上昇値
- レアリティ倍率
- その戦闘で使用済みか

候補を選ぶと、その場で現在の戦闘個体へココロリンクが発動する。

## 2. Phase 3で確定したルール

- 発動は通常行動を消費しない。
- 1体の戦闘個体が同時に受けられるリンクは1つまで。
- 効果は発動時の戦闘個体UIDへ紐づき、交代しても別の個体へ移らない。
- 交代後は、未使用の控えを新しい戦闘個体へリンクできる。
- 発動した効果はその戦闘が終了するまで保持する。
- 障壁を使い切っても、攻撃・素早さ強化は残る。
- 毒などの継続ダメージには障壁を適用せず、攻撃とこんらん時の自傷ダメージを防ぐ。
- ★1～★5の全モンスターが基礎リンクを使用できるが、★5は低倍率のみで追加固有能力を持たない。
- キャラクターはリンク元・リンク先とも現時点では対象外。

## 3. 効果の適用

Phase 1の計算結果を実戦へ接続した。

### ココロ障壁

受ける攻撃ダメージをHPより先に吸収する。残量は戦闘個体の状態欄へ表示する。量は対象最大HPの10～35％で、控えのレアリティにより決まる。

### 攻撃強化

プレイヤー側の攻撃倍率へ乗算する。強化量は10～35％で、控えのレアリティにより決まる。

### 素早さ強化

戦闘中モンスターの素早さへ10～35％相当を加算する。控え自身の素早さは使用しない。

### 素早さ強化

行動順の判定に使う実効素早さへ加算する。上限は対象の基礎素早さの30％。

## 4. 戦闘形式

通常戦、ボス戦、黄金郷、三つ巴戦、乱入戦で同じリンク状態と計算処理を使用する。三つ巴戦専用の別倍率や別使用回数は設けない。

## 5. UI方針

- スマートフォンの固定コマンド欄へ4つ目の補助コマンドとして配置
- 候補一覧はコマンド欄の上に重なるポップアップとして表示
- 控え2体を横並びで比較
- レアリティ補正を「適用済み」と明記
- 障壁・攻撃ダメージ・素早さを「最終効果」として表示
- 使用済み候補は無効表示
- 効果量を発動前に数値表示
- 発動後は戦闘個体の状態欄へリンク元と残り障壁を表示

## 6. 自動検証

`scripts/test-kokoro-link-battle.mjs` で次を確認する。

- 生存している控えから正常に発動できる
- 同じ対象へリンクを重複できない
- 失敗した発動で使用回数を消費しない
- 攻撃倍率と素早さ加算が対象UIDへ適用される
- 障壁が先にダメージを吸収する
- 交代後に別の対象へリンクできる
- 効果が発動対象UIDへ保持される
- 戦闘終了時のリセットで効果が消える
- 通常戦と三つ巴戦の両方が共通処理を参照する
