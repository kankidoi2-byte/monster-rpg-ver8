# 権能の基盤（2026-11-12）

本ブランチのみ。マージ・公開はユーザーの別途判断。台本・物語・報酬・既存 ID を変更しない。

## 現在の内容

- 序章完了後、育成画面に「権能」欄。中央 0 と周囲 7 マス。
- 0 の仮効果は味方の最大 HP +1%。画面に「仮の効果・仮の数値」と表示。
- 1〜7 は全て未開放。章名・効果は未表示。費用・クリック開放・機能ロック解除はない。
- 敵の HP、遠征の評価、G-BLESS の残量・補正は変更しない。
- 通常戦闘とストーリーの味方に適用。生存中の交代・回復の最大 HP も同じ計算。
- パーティー準備より難易度確定が後になる経路では、選択後に HP 比率を維持して再計算。死亡した仲間は復活しない。

## 追加セーブ

既存キー mb_v95c 内に authority を追加。既存キー・フィールドを削除しない。

- v: 1（本機能の形式）
- unlocked: boolean（序章完了フラグ、既存の完了／スキップ互換情報から開放を移行）
- clearedChapters: number[]（1〜7 の章クリア記録、現時点は空）

旧セーブは修復／保存時に加算移行。未完了の新規セーブでは非表示。既存の未知の authority 内フィールドは保全する。補正後 HP や仮の効果数値をセーブに書き込まないため、調整後に補正が累積しない。

## 将来のデータ差し替え

js/authority-data.js が効果・数値と難易度設定の編集箇所。現実装の数値処理は maxHp の percent 合計で、0 は 1%、他は空配列。新たな種類の補正は、その仕様の決定後に該当計算への接続とテストを追加する。

enabledByDifficulty は d1〜d5、extreme を全て true。false にした難易度では権能補正が無効。古い easy / normal / hard は d1 / d2 / d4 に対応。ストーリーの normal は d2 に対応。プレイヤー用の切替 UI はない。

将来各章を実装したら、その章の node.implemented を true にし、確定した効果データを入れる。章クリアを保存する既存トランザクションの中で recordAuthorityChapterClear(章番号, 保存対象) を呼ぶ。費用・報酬・独立した書込みは発生しない。二重呼び出しは冪等。現在は全章 implemented:false のため、この関数を呼んでも未実装章は開放しない。
