# ココロリンク Phase 5-1：水鏡の護り

更新日：2026-08-26
状態：実装・自動検証・統合・公開完了

## 1. 変更理由

Phase 5-0の実データ分析で、★3水のリンク元3体が、戦闘中コスト未実装のため追加能力「水脈節約」を利用できないことが分かった。レアリティ倍率は維持し、★3水だけが追加能力を持たない不均衡を解消する。

## 2. 確定仕様

- 能力名：水鏡の護り
- 対象：リンクを受けた戦闘中モンスター
- 効果：次に受ける直接ダメージを30％軽減
- 消費：ダメージを受けた1回だけ
- 発動率：100％
- 処理順：直接ダメージ算出後、水鏡の護り、ココロ障壁、HPダメージの順
- 対象外：毒・火傷などの継続ダメージ、反動ダメージ
- 交代：リンク対象UIDへ保持し、別のモンスターへ移らない

100ダメージを受け、ココロ障壁が20残っている場合は、水鏡の護りで30軽減し、残り70から障壁が20を防ぎ、HPへ50ダメージを与える。

## 3. 表示とログ

リンク候補と発動中の詳細へ「水鏡の護り（次に受ける直接ダメージを30%軽減・1回）」と表示する。発動前は「待機中」、発動後は「使用済み」とし、軽減時は軽減したダメージ量をバトルログへ表示する。

## 4. 互換性

既存ID `cost_reduction` は無属性「原初選択」の将来候補として残す。水属性の能力割当には新規ID `water_mirror_guard` を使用し、既存IDの意味を変更しない。セーブ形式と保存キーは変更しない。

## 5. 検証

- 100ダメージを30軽減して70にする。
- 2回目の直接ダメージでは軽減しない。
- ココロ障壁より先に軽減する。
- 発動中表示が「待機中」から「使用済み」へ変わる。
- 通常戦と三つ巴戦が共通の防御処理とログを使う。
- 実在する★3水3体が保留なしの能力を取得する。
- 既存の★1光「光護の一閃」、基礎リンク、他の★3能力、セーブ互換を維持する。
- 公開版でPhase 5-1のスクリプトと更新お知らせが反映されたことを確認する。
