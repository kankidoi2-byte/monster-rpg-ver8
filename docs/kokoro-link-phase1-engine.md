# ココロリンク Phase 1：計算エンジン

状態：実装完了（2026-08-26 計算基準修正）
対象：戦闘中モンスター基準のリンク効果計算

## 1. 現行仕様

控えモンスター自身のHP・素早さ・技威力は、リンク効果量の計算に使用しない。控えはレアリティ倍率と、将来のリンク能力を提供する。

```text
最終効果率 ＝ 基礎リンク率10％ × 控えのレアリティ倍率
```

最終効果率を、現在戦闘中のモンスターへ適用する。

```text
障壁       ＝ 戦闘中モンスターの最大HP × 最終効果率
攻撃強化   ＝ 攻撃ダメージ ×（1＋最終効果率）
素早さ加算 ＝ 戦闘中モンスターの素早さ × 最終効果率
```

## 2. レアリティ別の最終効果率

| 控えのレアリティ | レアリティ倍率 | 最終効果率 |
|---|---:|---:|
| ★1 | 3.5倍 | 35％ |
| ★2 | 2.6倍 | 26％ |
| ★3 | 1.9倍 | 19％ |
| ★4 | 1.3倍 | 13％ |
| ★5 | 1.0倍 | 10％ |

レベル補正は採用しない。同じレアリティなら、控えの種類・レベル・錬成個体補正にかかわらず、同じ戦闘中モンスターへ与える基礎効果量は同一になる。

## 3. 計算例

戦闘中モンスターが最大HP351・素早さ100の場合：

| 控え | 障壁 | 攻撃ダメージ | 素早さ |
|---|---:|---:|---:|
| ★1 | 123 | +35％ | +35 |
| ★2 | 91 | +26％ | +26 |
| ★3 | 67 | +19％ | +19 |
| ★4 | 46 | +13％ | +13 |
| ★5 | 35 | +10％ | +10 |

端数は整数へ丸める。

## 4. プロフィール生成

`buildKokoroLinkProfile(monster, instance)` は、個体情報、レアリティと倍率、最終効果率、主属性、★1～★3の能力帯を返す。★4・★5には固有リンク能力を付与せず、キャラクターはモンスター用ココロリンクの対象外とする。

## 5. 表示ルール

候補カードでは、倍率が最終効果へ二重に掛かるように見えないよう、次を分けて表示する。

- `レアリティ補正 ×3.5（適用済み）`
- `最終効果：障壁123 / 攻撃ダメージ+35% / 素早さ+35`

## 6. 安全性と検証

- 最大効果率は35％
- 入力した戦闘中モンスターのデータを変更しない純粋計算
- 不正な数値を有限値へ補正
- 同レアリティの控えは同一対象へ同じ効果を出す
- セーブデータ形式の変更なし

自動テストは `scripts/test-kokoro-link-engine.mjs` と `scripts/test-kokoro-link-battle.mjs` で行う。
