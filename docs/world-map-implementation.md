# 世界地図 初期実装仕様

2026-09-06。監査文書の提案に対し、この文書は現在実装した判断を記録する。

## 現在の範囲

通常のバトル入口は既存battleChoicesを使った地図/場所一覧へ。既存チュートリアルの専用カード/救援経路は先に評価して維持する。物語の新地図案内はまだ完成していない。地点選択はブラウザ内の一時状態で、セーブ再読み込み後の場所復帰は未実装。

地形は手書きSVGの仮素材。地名はHTMLボタン。横スクロールと同等の場所一覧を用意。正式地図画像と世界全体への影響演出は未完成。

## 遭遇と保存

- worldMapは独立の追加フィールド。SAVE_KEY、schemaVersion、TUTORIAL_VERSION、既存IDは変更しない。initSave/repairSaveで正規化する。
- activeの独立key: elysia/crisis/rift/water_secret/starsea/golden_land。発見後は勝利か危機の明示見送りまで保持。時限消失や画面更新による抽選なし。
- 通常探索の勝利結果を単体戦/複数戦双方で処理。history.winsを利用したworld-victory番号で再処理を防止。旧勝利の遡及抽選はしない。イベント/特殊領域/未完了チュートリアルは新規抽選しない。
- 通常マップは従来の条件と乱入/三つ巴の確率を維持。出発時の候補でrequest用enemyIdsも絞り、乱入から限定種が混入することを防ぐ。
- 特殊イベントからの戦闘は一対一に固定。特定の試練/危機/入口について解決対象を明確にする初期仕様。通常探索の戦闘モードは変えない。
- 暫定率: Normal以上で危機3%、秘境12%、星海10%、黄金郷はNormal3/Hard5/Extreme8%。光の平原でのNormal以上の勝利には降臨8%。保証回数/救済は未実装。実プレイ比較で要調整。
- 女神hikariは既存の契約不可を維持。降臨がHardの専用遭遇になる。契約解禁を行ったと報告しない。
- 危機doom_nemesionはExtreme。討伐/見送り双方で同じ偽竜3種の機会。未消化の順番は維持、新規危機では開始種を巡回。偽竜は1種勝利ごとに次へ進む。
- 星海の平常イベントは★4nemesion/Hard。錬成限定elixionは候補に加えない。
- 黄金郷は実在候補に合わせHardのみ。予約地図と自然入口は別経路とし、自然入口では予約地図を消費しない。予約地図は既存beginChosenBattleの確定時に消費。
- historyは最新30件。将来のworldId/eraId等の未知フィールドは保存するが、別時間軸への移動UIは未実装。

## 検証制約

Node VMテストは実ブラウザ/実機検証ではない。PlaywrightのJSパッケージは利用可能だがChromium実体がなく、公式インストーラのダウンロードがタイムアウトした。未確認を合格扱いにしない。CIと実機確認、正式素材、チュートリアル改修、収益比較、公開承認は別途必要。
