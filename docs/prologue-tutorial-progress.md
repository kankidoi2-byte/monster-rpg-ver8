- STEPには `advanceOnTarget`、`externalAdvance`、`waitForEvent`、`persistAs` があり、会話送りと実操作待ちは既に基礎的に分離されている。
- 実操作待ちではNextを隠し、対象操作成功時だけ `tutorialNext(true)` へ進む。
- 中断位置は `save.progress.tutorial.stepId` へ保存され、メニューから再開・スキップ・再閲覧できる。
- 現行導入はホームで「ようこそ、契約者。」から始まる機能案内。名前入力、世界への降下、キャラクター立ち絵、エルナ救援の物語は未実装。

### セーブと移行

- セーブキーは `mb_v95c`。変更禁止。

### 初戦と戦闘遷移

- 現行初戦は草原 `grassland` のスライム `slime`、Easy、通常の1対1依頼として実装されている。
- 失効した依頼参照は再生成し、画面が `battle`、味方と敵の両方が生成できた場合だけSTEPを進める。空の戦闘画面対策は再利用できる。
- 勝利・敗北・撤退は `handleTutorialBattleOutcome()` へ通知され、勝利は契約、敗北・撤退は再挑戦へ分岐する。
- 現行の複数敵実装は三つ巴で、敵同士も攻撃する。エルナ救援の「味方対複数スライム」へそのまま流用すると意味が変わる。
- 安全なMVPはスライム2体を連続ウェーブとして扱い、既存の単体戦・パーティー処理を再利用すること。複数敵を同時表示する新陣営仕様は本計画の範囲を超えるため採用しない。
- 初戦味方はフレイガル契約体、アクアロン契約体、本人エルナGUESTの3枠とし、GUESTは勝利・敗北・中断の終了時に必ず破棄する。
- 通常攻撃専用コマンドは現行にない。現在の「技」コマンドを通常攻撃相当の低コスト技として案内するか、専用操作を追加するかをPhase 6の実装前にコード契約として固定する。

### 現行契約と新しいエルナ契約

- 契約後はGUESTを破棄し、`elna_beginner` 契約体を一度だけ付与する。契約済みフラグと所有確認の両方で二重付与を防ぐ。
- グノーシスの台詞「契約！ 契約を貰って！」とエルナ本人の同意を、契約確定前に必ず表示する。

- 派遣後は遠征を稼働状態のまま残し、「帰還を待たなくていいぞ！」と案内して序章終幕へ進む。遠征報酬の即時受領や既存の帰還条件の短縮は行っていない。

- ホームへ「第1章への道」を表示し、自由行動へ移った後に冒険拠点を開ける導線を追加した。第1章の本編コンテンツ自体は未実装のため、現時点では解放済みの冒険機能へ案内する。
- 再プレイでは遠征を新規作成せず、派遣の振り返りから終幕演出だけを再生する。グノーシスは図鑑へ登録せず、カナタは序章へ登場させていない。
