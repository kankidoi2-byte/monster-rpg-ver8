## 完了済み

### Phase 1：三つ巴バトル画面改修

- 敵A・敵Bをスマートフォン縦画面内で比較しやすい横並びカードに変更。
- 画像、名前、HP、状態異常、ステータス変化、撃破状態を常時表示。
- 通常タップの詳細表示と、技選択後の対象決定を同じカードへ統合。
- 撃破済み対象の選択防止、生存対象への自動切替、乱入時の表示統一を実装。
- Androidスマートフォンで実ゲーム確認を完了。
- `scripts/test-three-way.mjs`へUI・対象選択・乱入・終了時復帰の検査を追加。

### Phase 2：錬成ワークベンチUI

- PR #12の通常／指定錬成案は採用せず、PR #13のワークベンチUIで置き換えた。
- 指定錬成を廃止し、素材4枠の種類・個数から結果が決まる通常錬成へ統一。
- 触媒モンスター1体を必須消費とし、パーティー中・遠征中・ロック中などの個体を除外。
- 50／100／250コイン、成功率、錬成傾向、素材不足を一画面で確認可能。
- 完成モンスターは錬成完了まで非公開。
- ルミナを予測欄へ常設し、現在の投入内容に応じて案内を変更。
- 指定錬成と旧残響UIの残存を自動検査で禁止。
- `scripts/test-alchemy-workbench.mjs`で現行仕様を検証。
