## 完了済み

### Phase 1：三つ巴バトル画面改修

- 敵A・敵Bをスマートフォン縦画面内で比較しやすい横並びカードに変更。
- 画像、名前、HP、状態異常、ステータス変化、撃破状態を常時表示。
- 通常タップの詳細表示と、技選択後の対象決定を同じカードへ統合。
- 撃破済み対象の選択防止、生存対象への自動切替、乱入時の表示統一を実装。
- Androidスマートフォンで実ゲーム確認を完了。
- `scripts/test-three-way.mjs`へUI・対象選択・乱入・終了時復帰の検査を追加。

### Phase 2：錬成ワークベンチUI

- PR #12の通常／指定錬成案は採用せず、PR #13のワークベンチUIで置き換えた。
- 指定錬成を廃止し、素材4枠の種類・個数から結果が決まる通常錬成へ統一。
- 触媒モンスター1体を必須消費とし、パーティー中・遠征中・ロック中などの個体を除外。
- 50／100／250コイン、成功率、錬成傾向、素材不足を一画面で確認可能。
- 完成モンスターは錬成完了まで非公開。
- ルミナを予測欄へ常設し、現在の投入内容に応じて案内を変更。
- 指定錬成と旧残響UIの残存を自動検査で禁止。
- `scripts/test-alchemy-workbench.mjs`で現行仕様を検証。

### Phase 3A：保存項目と自動検査

- セーブ形式をv4へ加算移行し、`mb_v95c`を維持。
- 新規は未開始、v3以前の既存プレイヤーは完了扱いとして強制表示を防止。
- 状態、現在ステップ、完了、スキップ、再閲覧、11機能のガイド既読を正規化。
- 初回契約保証とチュートリアル契約書支給を別々の一度きりフラグで保護。
- `scripts/test-tutorial.mjs`で新規、移行、途中再開、完了、スキップ、再閲覧、既読、冪等性を検査。
- `scripts/test-save-migrations.mjs`をv4へ更新し、旧セーブが強制案内されないことを検査。

### Phase 3B：共通UIと進行エンジン

- 実画面を四方向の半透明レイヤーで囲み、対象操作を塞がずに照らすスポットライトを実装。
- 吹き出し、矢印、進捗、戻る、完了、確認付きスキップ、閉じて再開を共通部品化。
- 保存済み`stepId`からの再開と、完了・スキップ状態を維持した再閲覧を登録式フローで実装。
- メニューにチュートリアル入口を追加し、Phase 4の本編登録前は非保存のUI操作ガイドだけを表示。
- Escape、左右キー、フォーカス復帰、`prefers-reduced-motion`、Android縦画面向け配置を実装。
- `scripts/test-tutorial-ui.mjs`でDOM契約、操作透過、配置、キーボード、再開・再閲覧接続を検査。
