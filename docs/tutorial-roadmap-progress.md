### Phase 2：錬成ワークベンチUI

- PR #12の通常／指定錬成案は採用せず、PR #13のワークベンチUIで置き換えた。

- 触媒モンスター1体を必須消費とし、パーティー中・遠征中・ロック中などの個体を除外。
- 50／100／250コイン、成功率、錬成傾向、素材不足を一画面で確認可能。
- 完成モンスターは錬成完了まで非公開。

- 指定錬成と旧残響UIの残存を自動検査で禁止。
- `scripts/test-alchemy-workbench.mjs`で現行仕様を検証。

- `scripts/test-tutorial-ui.mjs`でDOM契約、操作透過、配置、キーボード、再開・再閲覧接続を検査。

### Phase 4A：新規導入・編成・ホーム案内

- 新規セーブだけをタイトル後に自動開始し、既存・完了・スキップ済みセーブは強制しない。
- グノーシスがプレイヤーを「契約者」と呼ぶ短い導入を追加し、長い物語は追加しない。
- 初期配布済み5体を実画面に表示し、好きな1〜3体を選ばないと進めないようにした。
- 最初の1体がリーダー、最大3体、あとから変更可能と案内。
- ホームの冒険、パーティー、コイン、下部メニューだけを短く案内。
- `first_hunt`で保存して停止し、Phase 4B前に必須チュートリアルを完了扱いにしない。
- `scripts/test-tutorial-phase4a.mjs`で新規・既存分岐、再開、5体、編成数、案内範囲、チェックポイントを検査。

### Phase 4B：初回依頼・戦闘・勝利

- 既存のEasy依頼生成を使い、草原`grassland`とスライム`slime`の入門依頼を固定表示。
- 敵・味方、HP、属性、ターン、技を実画面上で短く案内し、最初の技使用後は自由戦闘へ移行。
- 敵能力、技、行動順、経験値・コイン計算、素材抽選、契約者EXP付与は通常戦処理を維持。
- 敗北・撤退時は同じ依頼を再表示し、戦闘中の再読込は`first_hunt`から安全に再開。
- 勝利後に実獲得の経験値、コイン、素材、契約者EXPを説明し、保存済み`first_contract`でPhase 4Cへ引き渡す。
- 契約書支給と初回契約成功保証はPhase 4Cへ残し、このPhaseでは適用していない。
- `scripts/test-tutorial-phase4b.mjs`を追加し、`npm run check`の全検査が成功。
- 実装コミット：`30243ee`。

### Phase 4C：戦闘後契約・成長確認・必須チュートリアル完了

- 新規必須チュートリアル中の草原`grassland`・スライム`slime`・通常契約書・未使用状態だけを初回成功保証の対象にした。
- v3以前からの移行記録がある既存セーブ、完了、スキップ、再閲覧、対象外マップ・モンスター・契約書では保証しない。
- 確認時に通常契約書1枚の支給と消費、スライム加入、通常の契約成功EXP、支給・保証フラグ、`contract_success`を一度の保存へまとめた。
- 保存失敗時は全変更を戻し、成功時は保存後に既存の契約書ズーム3回と手形演出を再生するため、演出中の再読込でも二重加入や契約書だけの消失を防ぐ。
- 加入したスライムのカード、属性、技、一覧、以後の契約失敗、育成、パーティー編成を実画面で案内し、ホームで必須チュートリアルを完了する。
- 再閲覧では契約書支給・保証・実加入を行わず、加入後案内へ分岐する。
- `scripts/test-tutorial-phase4c.mjs`を追加し、対象条件、原子的保存、保存失敗ロールバック、二重処理防止、再閲覧、演出、成長案内、完了を検査。
- `npm run check`の全検査が成功。
- 実装コミット：`6ebc2b9`。

### Phase 5A：戦闘系の初回ガイド

- 三つ巴の初回開始時に、敵同士の攻撃、技選択後の対象選択、敵に倒された相手が契約候補外になることを3画面で案内。
- 乱入の初回発生時に、通常1対1戦の2〜4ターン目に発生することと、登場ターンは行動しないことを2画面で案内。
- ココロリンクの利用可能なパネルを初めて開いた時に、控え1体、ターン消費なし、効果の継続、一戦につき同じ控え1回を2画面で案内。
- 既存の`threeWay`、`invasion`、`kokoroLink`既読フラグを表示時に保存し、二度目以降の表示と保存を防止。別の案内表示中や保存失敗時は未読を維持して次回へ持ち越す。
- 三つ巴・乱入の抽選率、2〜4ターン目、敵AI、2体分報酬、契約候補判定、ココロリンクの効果と使用制限は変更していない。
- `scripts/test-tutorial-phase5a.mjs`を追加し、画面数、文言、発火点、既読保存、重複防止、保存失敗、既存戦闘契約を検査。
- `npm run check`の全検査が成功。
- 実装コミット：`7cbfba9`。
