# ココロリンク Phase 4-1：★1リンク能力

更新日：2026-08-26
状態：実装・自動検証済み、統合前

## 1. 実装範囲

Phase 4-0で確定した★1「数値強化」10種を通常戦と三つ巴戦へ接続した。能力はリンク先モンスターのUIDに保持され、交代しても同じ個体へ戻れば状態が残る。★2・★3の追加能力と★4・★5の固有能力は発動しない。

## 2. 能力一覧

| 主属性 | 能力 | 実戦効果 |
|---|---|---|
| 無 | 原初の万能強化 | 攻撃・障壁・素早さを各5％追加 |
| 火 | 炎心強化 | 攻撃ダメージを15％追加 |
| 水 | 水護障壁 | 最大HP15％分の障壁を追加 |
| 森 | 森命再生 | ターン終了時に最大HP5％回復、2ターン |
| 雷 | 雷速強化 | 素早さを15％追加 |
| 風 | 風渡り | 次の被攻撃1回を20％で回避判定 |
| 光 | 光護の一閃 | 次の被ダメージ1回を25％軽減 |
| 闇 | 闇命吸収 | 次の与ダメージ20％を回復、最大HP10％上限 |
| 星 | 星運上昇 | 次の確率判定1回へ15ポイント加算 |
| 竜 | 竜威増幅 | 次の攻撃技1回の技威力を15％追加 |

## 3. 計算と消費順

- 無・火・水・雷はリンク成立時に基礎リンクの最終効果へ加算する。
- 風と光は敵の攻撃がHPへ届く前に1回だけ消費し、回避または軽減の後にココロ障壁を適用する。
- 闇は実際に与えたダメージを基準に回復し、攻撃技が命中した時点で1回消費する。
- 星はねむりなどの補助技、毒・麻痺・こんらん、連続攻撃のうち、最初に発生した確率判定1回へ適用する。
- 竜は威力が1以上の次の技で消費し、同じ技の追加攻撃にも同じ威力補正を使う。
- 森は毒処理と戦闘不能判定の後、生存している場合だけターン終了時に処理する。

## 4. 表示

リンク候補カードと発動中カードへ「★1リンク能力」の名称と効果を表示する。戦闘中の状態欄には、能力名に加えて待機中・使用済み・残りターンを表示する。発動、確率上昇、回避、軽減、吸収、回復、技威力上昇はバトルログにも記録する。

- `scripts/test-kokoro-link-battle.mjs`：通常戦・三つ巴戦の共通接続と表示契約を検証。
