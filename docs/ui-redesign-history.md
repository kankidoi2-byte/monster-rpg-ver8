# UI再設計：実装記録

更新日：2026-08-14

この文書は、UI再設計の決定、実装、検証を別チャットでも再開できる形で残す。現在の進捗率と次作業は`ui-redesign-progress.md`、改修前の保護契約は`ui-redesign-baseline.md`、視覚ルールは`ui-design-system.md`を正とする。

## 目標

- 王道ファンタジーの明るい冒険ものとして、暗い内容の物語でも入口は明るくする。
- パズル&ドラゴンズ、モンスターストライクを意識し、それらを超える魅力を目標にする。
- 戦闘を最も気持ちよい瞬間にし、スタイリッシュさ、迫力、爽快感を重視する。
- 普段ゲームをしない人にも触りやすい、簡潔で詳細を開ける情報構造にする。
- 起動画面は維持し、それ以外は全面的な変更候補とする。
- 戦闘への入口、次の報酬と成長、モンスター画像を優先し、操作回数と説明量を減らす。
- スマートフォン縦画面を基準とし、ChromebookとPCでは中央のゲーム領域を広げる。

## フェーズ0〜3

- 改修前は19個の画面と、起動画面・CAUTIONオーバーレイが存在した。
- セーブキー`mb_v95c`、初期5体、既存ID、確定済み戦闘仕様を変更禁止とした。
- UI移行中も既存機能への互換導線を残す方針を採用した。
- ホームではおすすめ討伐、現在のパーティー、次の成長、遠征帰還を優先した。
- 下部ナビはホーム、モンスター、バトル、育成、メニューの5項目とした。
- 実装コミット：`8cfea45 feat: establish bright mobile-first UI redesign`

## フェーズ4 戦闘UI

- 敵と味方の画像・HPを中心に置き、状態、経験値、長いログを段階表示へ移した。
- 技と契約・道具・逃走を下部へ固定し、操作までのスクロールを削減した。
- 勝利、敗北、撤退の結果パネルへEXP、コイン、ターン数、次の依頼を表示した。
- 三つ巴では対象候補を発光し、敵画像のタップとキーボードで選択可能にした。
- 即時HPバーと遅れて追従する確認バー、ダメージ数値、短いヒットストップを追加した。
- 属性別の色と光、高威力技の強い反応、技ボタンの威力・補助表示を追加した。
- 低い画面ではマップ詳細、画像、ログを段階的に圧縮した。
- 実装コミット：`0852c62`、`840f728`、`1eadc67`、`8ec3723`

## フェーズ5 討伐依頼・モンスター

- 依頼3択をマップ背景とモンスター画像が主役のカードへ変更した。
- 難易度、敵レベル、報酬倍率を常時表示し、説明、推定HP、攻撃倍率、特殊条件を折りたたんだ。
- 三つ巴と乱入の重要情報は初期表示に残した。
- パーティーの装備技と敵属性、平均レベルから候補内のおすすめを1件表示する。表示だけに使用し、抽選やバランスは変えない。
- 手持ち、編成、図鑑はモンスター画像中心の明るいカードへ変更した。
- 育成アイテム、個体情報、装備技は必要時に開く構成へ移した。
- 実装コミット：`7f8fd9f feat: redesign quest and monster screens`

## フェーズ6 育成・錬成・遠征・その他

- 技変更では検索・絞り込みを折りたたみ、入力部品とカードを共通UIへ統一した。
- 遠征では使用枠、進捗、適性、帰還状態、受領報酬を上段で判断できるようにした。
- 合成と錬成では既存の消費確認、成功率、候補、警告を維持し、明るい共通パネルへ移した。
- ショップは価格、所持数、購入操作を優先し、バトル履歴を折りたたんだ。
- アイテムガチャとアイテム図鑑も同じカード・色・余白へ統一した。
- ゲームロジック、価格、成功率、報酬、セーブ形式は変更していない。

## 互換性と検証

- セーブキー`mb_v95c`、既存モンスター・アイテム・技・マップ・レシピ・個体UID・図鑑番号は維持している。
- 起動画面のロゴ、背景、Touch to Start、モンスター演出を維持している。
- 三つ巴、乱入、難易度、遠征、黄金郷、錬成の既存仕様を維持している。
- 自動検査対象は48モンスター、19マップ、26アイテム、3合成、2錬成レシピ、74画像、21画面、21 DOM契約、17スクリプトである。
- JavaScript構文検査、データ、画像容量、UI契約、三つ巴、遠征、黄金郷、空白エラー検査を各フェーズで通過させている。
- AndroidとChromebookでの一括手動確認は、ユーザーの判断によりフェーズ8へ集約する。
