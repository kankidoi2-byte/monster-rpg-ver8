# クラッシュ／ラッシュ部分一致の修正

調査基準は開発元main `12b45ec58e407ab5935ca443d547004447c8c7f2`。
AGENTS.md、risk-approval-contract.json、技編成レビュー、偽竜置換仕様、技演出仕様と現行分類／装備／表示処理を確認。

## 原因と範囲

`skillFormFor` は最初に一致したルールのformを採用する一方、`skillRequirementsFor` はtagを持つルールだけを探す。打撃ルールのtagはnullのため、クラッシュ技はstrike演出でもラッシュ部分一致から `capability:charge` を要求していた。
装備画面の「区分・属性・タグ条件に合いません」、装備可能のみのフィルター、実装備可否はこの条件を利用する。表示名・属性・威力の重複問題とは別。

| 固定ID | 技名 | 修正前 | 修正後 |
|---|---|---|---|
| skill_thornbeat_03 | スパイクラッシュ | strike＋突進条件 | strike、突進条件なし |
| skill_icegolem_03 | 凍結クラッシュ | strike＋突進条件 | strike、突進条件なし |
| skill_proto_icegolem_05 | 巨岩クラッシュ | strike＋突進条件 | strike、突進条件なし |
| skill_proto_icegolem_03 | 大氷河クラッシュ | strike＋突進条件 | strike、突進条件なし |

最新316技でクラッシュを含むのは4技。巨岩クラッシュの個体専用条件は維持。
凍結クラッシュと大氷河クラッシュをアクアロン、ハイアクアロン、シェンハイロン、ティエンハイロン、精霊スイレンが新たに装備可能（2技×5体）。他の装備可否は変わらない。

突進ルールのラッシュだけを `(?<!ク)ラッシュ` に変更。独立ラッシュ、フレアラッシュ、既存のガイアスラッシュ、突進、急降下、ダイブ、ランページ、チャージを維持。
両方の語を含む現行の登録技はない。将来の「クラッシュラッシュ」「クラッシュ突進」等には既存のstrike優先formと突進条件を維持し、先頭一致へ統一する設計変更は行わない。
ガイアスラッシュに含まれるスラッシュの扱いは別の名称設計判断であり今回変更しない。
