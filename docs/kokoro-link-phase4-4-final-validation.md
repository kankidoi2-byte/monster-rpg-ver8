# ココロリンク Phase 4-4：総合検証と仕上げ

更新日：2026-08-26
状態：実装・自動検証・公開完了

## 1. 目的

Phase 4-1～4-3で実装した★1～★3の追加リンク能力をまとめて検証し、Phase 4を完了可能な状態へ仕上げる。

## 2. 受け入れ条件

- 通常パーティー3体のうち、戦闘中1体に対して控え2体がリンク候補になる。
- 基本効果は戦闘中モンスターの最大HP・攻撃ダメージ・素早さを基準にし、リンク元のレアリティだけで補正する。
- レアリティ補正は★1＝35％、★2＝26％、★3＝19％、★4＝13％、★5＝10％。レベルは補正に使わない。
- ★1は数値強化、★2は属性・状態異常、★3は戦術支援を主属性ごとに1つ持つ。
- ★4・★5には追加リンク能力を付けない。
- 通常戦と三つ巴戦で、発動・対象選択・一度きり効果の消費・戦闘終了時のリセットが一致する。
- 発動中の基本効果と追加能力の状態を、戦闘画面から再確認できる。
- 既存セーブ、戦闘、図鑑、錬成、遠征などの全体検証を通過する。

## 3. Phase 4-4の変更

公開版を実機操作した結果、ココロリンク発動後に「発動中」ボタンが無効化され、残り障壁や一度きり能力の状態を再確認できない問題を確認した。発動後もボタンを有効にし、リンク詳細パネルをいつでも開けるように修正した。候補カードは発動済みのため無効のままとし、重複発動は許可しない。

## 4. 検証

- 公開版でタイトル、ホーム、パーティー3体編成、討伐選択、通常戦開始、リンク候補、発動ログを確認。
- 公開後、「発動中」ボタンが有効なことと、残り障壁・攻撃・素早さ・追加能力を再表示できることを確認。
- `scripts/test-kokoro-link-phase4-complete.mjs` で5レアリティ×10属性＝50組を検証。
- 各組について、補正率、レベル非依存、能力帯、主属性への能力割当、★4・★5の追加能力なしを検証。
- 既存のPhase 4-1～4-3テストで各能力の発動、成功率、持続、消費、対象、保留能力を検証。
- 全体チェックで既存機能とセーブ互換性を回帰検証する。

## 5. 保留事項

水属性★3と無属性★3の「技コスト軽減」は、戦闘中に消費するコスト資源が存在しないため引き続き保留する。これはPhase 4の不具合ではなく、将来バトルコストを導入する場合の接続点として残す。

## 6. 完了判断

自動検証、統合、公開版での発動中パネル再表示まで確認したため、ココロリンクのPhase 4は完了とする。以後はPhase 5として、実プレイデータに基づくバランス調整、または戦闘中コスト資源の設計を別案件で扱う。
