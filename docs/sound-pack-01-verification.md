# サウンド第1弾 実装・確認記録

仕様の正本: [第2版](https://docs.google.com/document/d/1DwiEls8q4XmIA-k3fefx2xCWLLIxRSus5JxolYXNi0U/edit)

## 素材と実装

- 指定されたファイルIDから3曲と10効果音をコピー。Drive側は変更していません。
- `sound-manifest.json` はDriveの原本と同内容。SEは元ファイルとのサイズ・SHA-256一致、BGMは元ファイルの記録とAAC変換後のSHA-256を `scripts/sound-pack-01-assets.json` とテストで固定。
- Web Audioの共通再生機構、画面・戦闘の音のみのフック、設定画面を追加。ゲーム本体セーブには変更なし。音設定専用キー `monster_game_audio_v1` を使用。
- BGMは操作後、その場面の1曲だけ読み込み。効果音10個は初回操作後に読み込み。非表示ではAudioContext全体を停止し、復帰時は続きから再生。
- 斬撃の分類は既存技のformを使用。重斬撃は名前に「大剣・重斬・重い斬・渾身斬り・呪鉄斬」がある剣系、その他の剣・爪は軽斬撃。フレイムクローは軽斬撃後0.1秒で炎。未採用音は追加しません。

2. **ループ継ぎ目**: home 85.075–159.405秒、grassland 14.420–41.425秒をAudioBufferSourceNodeへ設定することを検証。実機での隙間・クリック音の聴感確認は未実施。
3. **ホーム⇄マップの継続**: 同じsourceと開始時刻が維持されることを自動検証。
4. **SEと無音スキップ**: 10キー、左右チャンネル双方の-50dB閾値、0.025秒重複抑止、0.1秒ずらし、未採用キー拒否を検証。音量の実機聴感調整は未実施。初回ダウンロード中の最初の音には取得待ちがあり、未取得音を合成音で代用しません。
5. **起動速度**: 操作前は音声リクエストもAudioContextも作らないこと、操作後も全BGMを一括取得しないことを検証。Androidの実測起動時間比較は未実施。
6. **設定保存**: BGM/SEの独立音量とミュート、再読み込みによる復元、破損設定・保存不可時にゲームセーブを壊さないことを検証。

**Android/iPhone実機は使用していません。自動検証の合格は実機での聴感・操作確認を意味しません。**

## 2026-11-07: BGMのAAC-LC変換（PR #339追補）

指定Drive IDから3曲を再取得し、原本のSHA-256が初回コピーと一致することを確認して変換しました。Drive原本は保持。SE 10個、manifest、loopStart / loopEnd、再生コードは変更していません。

変換コマンド（ffmpeg 7.1.5）: `ffmpeg -i 元ファイル -c:a aac -profile:a aac_low -b:a 192k -ar 48000 -ac 2 出力.m4a`

ffprobeで3曲ともOpus / 48kHz / 2chからAAC / LC / 48kHz / 2chになったことを確認。192kbpsはエンコーダの目標値であり、測定平均値は約192.8〜193.2kbpsです。

| 曲 | 元の長さ・サイズ | 変換後の長さ・サイズ |
|---|---|---|
| title | 202.800秒 / 3,448,381 bytes | 202.813秒 / 4,936,290 bytes |
| home | 172.600秒 / 3,176,328 bytes | 172.613秒 / 4,194,671 bytes |
| battle_grassland | 71.200秒 / 1,275,253 bytes | 71.213秒 / 1,731,534 bytes |

### 開始位置の検証

- ffprobeのstart_timeは元・変換後とも全曲0.000000秒。
- 元と変換後をffmpegで48kHz stereo float PCMへ復号。0 / 1 / 5 / 15 / 30 / 60秒から各2秒間を、左右別に相互相関で±4,800サンプル（±100ms）探索。全36比較で最良のずれは **0サンプル（0ms）**。ゼロ位置の相関係数の最小値はtitle 0.989123、home 0.999271、grassland 0.997265。
- コンテナ上の長さは各曲+0.013秒。復号サンプル数はtitle 9,735,048→9,735,168、home 8,285,448→8,286,208、grassland 3,418,248→3,419,136で、末尾のフレーム／パディング差があります。これは開始位置のずれとは区別し、切り詰め・無音追加・位置補正は行っていません。
- ループ位置home 85.075–159.405秒、grassland 14.420–41.425秒は変更なし。変換履歴、原本ID・ハッシュ、変換条件、出力ハッシュ、相関結果を素材記録へ保存しました。
- ffmpeg上の測定結果であり、端末ごとのWeb Audioデコーダや実機での聴感差を保証するものではありません。Android / iPhone / iPadの実機は利用できず未検証です。
