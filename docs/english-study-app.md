# 英語学習ノート 初版

## 範囲

- `/english/` に独立したスマホ用学習アプリを追加。ホームからリンク。
- 基礎〜TOEIC600点を目指す教材。TOEIC公式問題や得点保証ではない。
- 初期30語、2026-09-14〜2026-09-23の10日分。教材は日付固定。
- 毎日3語、意味4択、学習済み単語の例文穴埋め、解説、復習、検索できる単語帳。
- 正解時に学習記録を保存。新規・期限到来の復習は同一単語1日1pt。誤答後の再挑戦も対象。期限前の自主練習は加点なし。
- 日付はAsia/Tokyo。復習間隔は1/3/7/14/30日。誤答で翌日に戻す。
- ポイントは獲得日と単語IDの組の集合から計算。保存成功後に加点表示。
- 100pt交換のアイテム付与は未実装。準備中表示のみでポイント消費しない。

## 保存と互換性

`mb_english_v1` の独立したlocalStorageのみ使用。本編の`mb_v95c`には読み書きしない。
Web Locks内で最新版の保存値を読み、採点とポイントを一括保存。複数タブの同時加点を直列化。
バックアップは型・日付・単語IDを検証して統合。同じ獲得イベントを重複加算しない。
読めない保存は自動削除しない。「記録」画面から元のJSONを書き出せる。
スマホ内保存なのでデータ削除・別ブラウザ・端末間で自動同期しない。ローカル改変や時計操作への厳密な不正防止は対象外。

## タスクと共通教材

- アプリ: `english/curriculum.json`
- タスク: `english/lessons/YYYY-MM-DD.json`
- 全日付ファイルとcurriculumの内容一致を`npm run check:english`で検証。
- 共通教材公開を確認してから、既存22:15タスクを日付ファイル参照へ更新する。
- タスクは当日ファイルの3語と意味・例文・和訳・語源をそのまま使う。取得失敗・未登録ならその旨を通知し、独自の3語に置き換えない。
- 既存過去配信本文はPersonal Contextから取得できず、過去分を捏造していない。
- 初日3語の辞書参照を確認。その他の語源は未確認と明記し、架空の由来を作らない。例文は独自作成。
- 教材の補充は、日付ファイルとcurriculumを同時更新する。登録最終日より先は未登録表示となる。

## 検証

`npm run check:english`: 共通教材一致、単語ID一意、選択肢、空欄化、JST日跨ぎ、誤答→再挑戦、日次上限、復習間隔、JSON往復、バックアップ統合と不正形式拒否。
`npm run check`: 既存の全体検査。
実ブラウザで360/390/768pxの表示、学習フロー、再読み込み、検索、書き出し・読込、本編セーブ維持を確認する。
Android実機での最終操作確認はユーザーに依頼する。
