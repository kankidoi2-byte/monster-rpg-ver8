# 技図鑑・入手・合成UI

## 入手配分（担当者判断）
106種類はモンスターとキャラクター共通の技カードガチャへ登録する。最強4種類は排出しない。1回100コイン、10回900コインは既存価格を維持。

通常抽選は低級80%、上級17%、超級3%。同じコスト内は均等抽選。コスト別割合は1:30%、2:20%、3:15%、4:10%、5:5%、6:2%、7:7%、8:3%、9:3%、10:2%、12:0.3%、15:1.2%、16:0.5%、17:0.3%、20:0.7%。採用技が存在するコストのみ対象。

10枚とも低級だった場合のみ、最後の1枚を上級・超級から重みを再正規化して再抽選する。このため10連の最終分布は通常抽選と異なる。保証再抽選では上級85%、超級15%。以前のキャラクター限定共通技保証は、双方共通の上級以上保証へ置換した。技のレアリティは設けず、分類はコストだけから求める。

根拠：基本技を厚く配り、上位技の試行機会を残す。106種類すべて通常抽選で正の確率を持ち、最強技への素材集めが可能。新通貨は作らない。

## UI

図鑑は通常使用110種類だけ。分類、属性、コスト（25まで）、攻撃／補助、効果で絞り込む。短い自然文は一覧、詳細数値は展開表示。適性と装備可能ユニット、初期装備ユニット、入手方法を表示。最強技には超級合成からの抽選入手と、最強合成での再抽選を案内する。合成への入口は育成だけ。

合成は「モンスター → 育成 → 技合成」からだけ開く。4つの級から選び、同級の所持カードを＋／−で必要枚数選択する。同じカードの複数枚指定も可能。素材3枚（最強2枚）を消費してランダムな1枚を獲得する。低級→上級30％、上級→超級25％、超級→最強10％、最強は同級100％。降格なし・追加費用なし。級内は全60／30／16／4種類から均等抽選し、素材や所持済みカードも排出する。天井はない。候補一覧と1技あたりの確率を展開して確認できる。

実行前の確認には素材名・枚数・級別確率を表示し、装備解除が必要な場合はユニット名・UID・技名・枠を明示する。保存成功後だけ、短い合成演出→完成級→技カード・詳細効果を表示する。結果表示を閉じたり画面を移動してもカードは保存済み。プロフィールやセーブの切替では前の選択と結果を消す。保存失敗では結果演出を出さず、素材選択を維持して同じ抽選結果で再試行できる。

レイアウトは幅320〜430pxを含め一列へ縮小できるCSSグリッド、折返し可能な名称、44〜48px以上の操作ターゲットを使用。装備一覧でもコスト1〜20／25の個別検索と4分類の検索を提供し、旧技は一覧に出さない。

図鑑の詳細数値は採用カタログの detailedDesc をそのまま表示し、威力とCOSTはヘッダーにも表示する。倍率・確率・反動・回復式は短い説明に混ぜず展開表示で確認できる。合成画面の効果詳細も同じカタログを利用する。
