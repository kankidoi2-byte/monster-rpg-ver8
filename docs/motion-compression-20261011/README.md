## 再現用エンコード（候補作成時）

```sh
ffmpeg -c:v libvpx-vp9 -i ORIGINAL.webm -map 0:v:0 -an \
  -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 0 -deadline good \
  -cpu-used 4 -threads 2 -row-mt 1 -auto-alt-ref 0 -crf 28 OUTPUT.webm
```

FFmpeg 7.1.5。alphaを正しく復号するため入力側libvpx-vp9を明示。ローカルCPUでの復号中央値は原本→候補がキメラグナ2.852→2.125秒、スライム0.438→0.395秒、エリクシオン1.975→1.510秒。各3回・単一スレッド・共有環境の参考値で、ネットワーク/ブラウザ/GPU/スマホ性能の実測ではない。
