## 3. Phase 1固定仕様：三つ巴バトル画面

`battle`を共通戦闘画面として維持し、三つ巴・乱入時は敵Aと敵Bを横に並べる。スマートフォン縦画面で、2体のHP・状態異常・ステータス変化と対象選択を同時に比較できることを優先する。

- 画像、名前、HP、状態異常、ステータス変化、撃破状態を常時表示。
- レベル、属性、素早さなどは通常タップで開く詳細へ収める。
- 技選択後はカードタップを攻撃対象の決定へ切り替える。
- 撃破済みの敵は選択不可。
- 行動前に選択対象が倒れた場合は生存対象へ自動切替。
- 敵AI、三つ巴・乱入の発生条件、報酬、契約判定は変更しない。
- 対象選択の補助ボタンとキーボード操作を維持。

この仕様はPhase 1として実装・実機確認済み。

## 5. Phase 3A固定仕様：保存項目と自動検査

`mb_v95c`と既存フィールドは維持し、`progress.tutorial`へ次を追加的に正規化する。

```js
{
  id: 'prologue',
  version: 1,
  status: 'not_started',
  stepId: null,
  completed: false,
  skipped: false,
  replaying: false,
  firstContractGuaranteeUsed: false,
  starterContractScrollGranted: false,
  guides: {
    threeWay: false,
    invasion: false,
    kokoroLink: false,
    alchemy: false,
    expedition: false,
    evolutionFusion: false,
    skillCards: false,
    goldenLand: false,
    dex: false,
    shopItems: false,
    contractorRank: false
  }
}
```

- 新規セーブは `status: 'not_started'` で開始。
- v3以前の既存セーブはv4移行時に完了扱いとし、初回必須チュートリアルと契約書支給を強制しない。
- 既存プレイヤーはメニューから開始・再開・再閲覧できる。
- スキップは確認を要求し、途中進行は `stepId` から再開。
- 再閲覧は元の完了・スキップ状態を消さず、初回契約保証と契約書支給を復活させない。
- 初回契約保証と契約書支給は別々の一度きりフラグで重複を防ぐ。
- 戦闘途中や錬成途中の一時UI状態は保存しない。

`scripts/test-tutorial.mjs`を追加し、新規、旧セーブ移行、途中再開、完了、スキップ、再閲覧、ガイド既読、初回契約関連フラグの冪等性を検査する。

## 7. Phase 4固定仕様：初回必須チュートリアル

新規セーブで一度だけ、5〜10分を目安に実画面で基本循環を案内する。

1. 短い導入（案内役グノーシス、プレイヤー呼称は「契約者」）
2. 初期配布済みの5体から好きな1〜3体を編成する
3. ホームから既存の草原・スライムの初回依頼へ進む
4. 技、HP・属性・ターンを知り、実際に勝利する
5. 経験値・コイン・素材・契約者Rank経験値を確認する
6. 一度だけ支給される通常契約書で、最初のスライムとの契約に必ず成功する
7. 加入したスライムのカード、属性、技、一覧、編成、成長を確認する
8. 以後の契約には失敗もあると伝え、次の成長目標を示してホームへ戻る

新しい章、人物、敵、イベントは追加しない。

初回契約保証は、新規必須チュートリアル中、草原のスライム、保証未使用の全条件を満たす場合だけ適用する。契約書は通常どおり1枚消費する。加入、消費、保証使用済みを整合的に保存し、演出中の再読込で二重加入や契約書だけの消失を起こさない。既存セーブ、スキップ後、再閲覧では保証を復活させない。
