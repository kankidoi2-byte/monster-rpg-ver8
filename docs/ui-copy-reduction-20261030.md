## チュートリアルと保存互換性

- 本編 `TUTORIAL_MAIN_FLOW_ID` の登録内容は基準コミットと文字単位で一致します。物語・台本・マップストーリーの本文には触れていません。
- 図鑑・ショップ・称号のガイドはステップID、順序、ターゲット、戻る/次へ、完了処理を保持し、表示する本文だけを短縮しました。称号の否定を繰り返していた見出しも「称号を飾る」にしています。
- 黄金郷2ステップは本編と別の非永続ガイドです。登録だけを削除し、既存フローIDと呼び出し口は保持しました。空のフローは既存ガードで終了し、再開位置・既読フラグ・セーブを書き換えません。
- `js/save.js` と `js/character-gacha.js` は、日本語文字列を除く構文木が基準コミットと一致します。分岐・関数呼び出し・確率・数値・保存内容は同一です。
- 道具の手番非消費、ストーリー戦の契約不可、不可逆操作の確認、`js/init.js` の書き出し案内、相性表凡例、状態異常説明、錬成の予兆・練習時の仲間非消費は保持しています。
