# キャラクター技・技ガチャ調整仕様

更新日: 2026-10-02。対象は序章追加12系統・36形態の専用108技と、キャラクター共通6技。これは採用するデータの変更表であり、数値バランスの最終確定を意味しない。

## 採用範囲

- 追加共通6技と、キャラクター技ガチャ10連の10枚目保証を追加する。単発100コイン・10連900コインを維持する。
- 10連の1〜9枚目は共通技を含む通常抽選。10枚目は追加共通技6種から選び、その時点で未所持の種類、全種所持なら所持数が最少の種類を同率で優先する。先に引いた9枚も所持数に含める。
- 装備可能キャラクターの表示追加と余剰カード交換は今回実装しない。
- 専用108技は全て別の名称に変更し、各形態の技を削除・統合しない。固定技ID・カード所持数・キャラクターID・能力値は維持する。旧名称から生成された技IDには互換対応を設ける。
- 共通技はキャラクター専用・無属性・職業制限なし。キャラクターの初期技や進化時の自動配布には加えず、技ガチャから取得する。

## バランス設計

- COSTは装備上限。戦闘時には消費しないため、威力の単純上昇だけでなく役割、状態条件、反動を分ける。
- 各形態の初期3技の合計COSTは★2で5以下、★3で6以下、★4で8以下。進化前の専用技も同系統の上位形態で使える。
- 同じ系統の9技に同一性能の技を置かない。全114の新名称は相互に重複せず、既存の他の技名とも重複しない。
- 攻撃力補正は基本値からの加算。強化上限160%、弱体下限65%。防御の軽減率は45%で次の被弾まで。溜めは次の攻撃1.2倍で重複不可。
- 条件攻撃はダメージを与える直前の状態で判定する。低HP条件は最大HPの半分以下。強化解除は攻撃後なので、同じ一撃で防御を無視する効果ではない。
- 吸収は実際に減らしたHPに比例する。反動は自分の最大HPに比例し、残りHP次第で倒れる。
- 毒・麻痺は3ターン、混乱は2ターン。新しい睡眠付与技は加えない。回復や補助を組み合わせた技でも追加効果は1回だけ発動する。
- 共通技は専用技を持たない役割を補う手段。専用の補助技が同等以上に効率的なケースは、キャラクターの個性として残す。
