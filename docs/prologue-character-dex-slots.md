# 序章キャラクター図鑑枠

参照: Google Drive「序章ガチャキャラクター制作状況」（2026-08-30更新、2026-09-06確認）。ユーザー指定資料の正式名・現在名方針を採用。

既存 C-001〜014（エルナ5・ステラ3・ルミナ3・エリシア3）を保持し、C-015〜050を予約する。カナタ・フィアは第1章のため含めない。モンスター図鑑番号と保存用IDは変更しない。

予約枠は `CHARACTER_DEX_RESERVED_SLOTS` で管理し、戦闘用 `M` には追加しない。図鑑では登場予定として名前・属性・★数を公開し、ガチャ・敵候補・錬成・所持数・収集済み数に加えない。将来 `M` に同じ `characterNo` を持つキャラクターを追加すると予約表示を置き換える。`slotId` は図鑑表示用で、保存用キャラクターIDではない。

ガチャは基本形（★2）のみ、★3・★4は育成で解放する計画。能力値、技、画像、進化レベル、敵出現先の実装は次工程。最近のレグス・ミレーユの画像構想は画像制作時に確認し、この枠設定では資料の正式名を維持。
