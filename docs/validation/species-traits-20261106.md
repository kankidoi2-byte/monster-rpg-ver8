# 種族特性の実装・検証記録

対象: 開発リポジトリ PR337 統合後 main（8526036）。
仕様: Google Drive「モンスターバトルRPG ver8｜特性 採用案｜2026-11-06」の「特性 仕様書.md」と sim-traits.mjs。

## 実装範囲

- 全100種の現在の姿から0〜2特性を導出。定義、割当、内部係数は js/traits-data.js に集約。
- セーブへの特性フィールド追加なし。回数・一時効果は戦闘中だけ保持。
- ステータス画面だけに数値なしの特性欄。★5の名残と空欄非表示。錬成の型とは別。
- 単体・三つ巴・乱入の実際の戦闘resolverに適用。敵には種族特性を付けない。オートも同じresolverを利用。
- 戦闘参加パーティの報酬特性は同系統を重ねず最大値。学び上手は本人だけ。撤退は経験値（+は素材も）の半分で、勝利・契約・コインを付与しない。
- 撤退素材は通常抽選後、アイテムIDごとの個数を半分にして切捨て。保存失敗時は同じ抽選結果で再試行し、再抽選・二重付与を防止。
- 撤退経験値は有効なG-BLESSを含めた勝利相当の半分。撤退は勝利ではないためG-BLESS残数を消費しない。
- 共鳴は基本リンク効果（攻撃・バリア・速度）の換算倍率に適用。現在の100体の割当に共鳴はない。追加能力の回数・継続時間は変更しない。
- ロードマップは「開発中」。ストーリー台本・台詞・保存キーは変更なし。

## シミュレーション

`N=150 npm run analyze:traits`。Lv40のフレイウルフ・ボルタックス・オルカアビス、敵Lv46/41/44、同種対戦、種ごと150戦、固定seed、味方だけに検証特性。
実装の実戦resolverを呼び、平均倍率への置き換えはしない。

| 特性 | 実装 通常/+ 勝率 | 参考sim 通常/+ |
|---|---|---|
| なし | 65% | 65% |
| 逆境 | 88/90% | 88/90% |
| 先制 | 84/89% | 84/89% |
| 属性の極み | 89/92% | 89/92% |
| 追い打ち | 74/80% | 74/80% |
| 連撃 | 75/80% | 84/89% |
| 貫き | 89/92% | 89/92% |
| 高揚 | 77/77% | 74/77% |
| 堅い守り | 74/82% | 74/82% |
| 威圧 | 71/77% | 71/77% |
| 再生 | 79/81% | 79/81% |
| 頑丈 | 65/65% | 65/65% |
| 反撃 | 88/89% | 89/92% |
| 状態付与:麻痺 | 68/74% | 70/76% |
| 状態付与:毒 | 72/79% | 76/83% |

連撃の参考simは常時平均倍率（1.075/1.125）で近似しているが、実装は仕様どおり15/25%で半威力の追加攻撃。高揚は仕様の3ターン目から（参考simは4ターン目から）。反撃は実際に失ったHPを基準にし、過剰ダメージを反射しない。確率処理は実際の乱数消費を伴うので状態付与等も参考値とは一致しない。参考目安に寄せるための係数改変はしていない。連撃の差はレビュー時の確認事項。

## 確認方法と未確認点

- 非ブラウザ既存/新規検査195本: 全通過。JSDOMによる全本番script読み込み、実際の序章救出2戦勝利、同種の敵への非適用/味方への適用の統合検査も通過（CIのDOM検査に追加）。
- 新規 check:traits: 全割当、UIの文言/エスケープ/古いデータ非変更、戦闘効果/回数、複数戦フック、報酬/撤退/保存失敗再試行。
- 既存検査のHP観測fixtureは、新しい薄い戦闘wrapperの内側（doAttackBase）を観測するよう追従。観測8箇所や過去不具合の検出は維持。
- ローカルのブラウザ起動は環境制限で不可。npm run check 全体の合否はPRのCIで確認する。
- Androidの実機で表示、応援・献身・疾風・見切り・浄化・固有特性等の動きを確認する必要がある。
- **このPRはマージ・公開しない。Android実機確認後のユーザー許可を待つ。**
