# 開発版のモバイル総点検

基点は開発mainの `c40a3351e86e8ad3628cc2a77b437097e6f4d735`。ブラウザはタッチ有効のChromium。初回は空のプロフィールで、会話、光っている操作、ボタン、技の威力、HPと所持品表示を使った。基本は412×915 CSS px。個別再現は別プロフィールの412×915と360×915。個別再現用に場面を設定した結果は、通しプレイの戦績に含めない。各話の開始・終了、実行ログ、終幕・ホームの写真はPRの通しテスト証跡を参照。

[初戦終了](first-win.webp) ・ [中盤](middle.webp) ・ [終幕完了](epilogue.webp) ・ [拠点復帰](home.webp)

## 初回プレイでの案内

- 第2話「下の『バトル』を押すと世界地図が開くぞ」から地図・出発・交代・技選択へ進めた。初戦は手動選択でスライムを討伐し、エルナの救援会話と「契約する」へ進んだ。[初戦](first-win.webp)
- 第3話はホームの「救援依頼を報告」と次画面の「報告して報酬を確認 ›」で、報告の案内を続けて読む。別々の操作であり、続く「報酬を受け取る」と「よし、受け取れた！」で結果も分かる。案内をどこまで短くするかは要判断。
- 第5話の「入門錬成を始める」は確認画面を開く操作。「まだ消費していない」と「消費して錬成を実行」で消費時点が明確。結果の「錬成成功！」まで確認した。
- 第6話は「短距離は、バトルに1回勝つと帰還する遠征だぞ！」と案内される。「草原へ短距離遠征」を押した後も続けて物語を進められた。第8話のショップは「物語に戻る」で復帰。[中盤・第12話](middle.webp)
- 第13話の敗北から「話一覧へ」で拠点に戻り、開設記念プレゼント、エルナの育成・進化、ショップと編成を使って再挑戦した。育成後の通常戦闘でモルグラムを退けた。難易度は要判断。

## 未マージPRの照合

- #364 のテストを再利用し、終幕後の拠点・一覧・権能・再読込を追加。内部の進行・HPも読む自動再テストは、画面表示だけで遊んだ初回と別に集計。
- #377 の背景と会話送りは両方ともmainで再現し、該当差分を使って検証。施設の見出しと第7話の契約戦績は既にmain側にある。#377も採用するときは重複を照合すること。
- #378 はホームのフリックとドットの診断。main側の既存ホームテストで即時・遅延タッチ、端での解放、キャンセル、360/412/430pxの境界判定が成功。不定期事象の消滅までは断定できない。
- #182 は戦闘効果音の追加。今回の再現4件との重複なし。

スクリーンショットは隔離したテストプロフィール。チェック対象はブラウザ版の開発ソース。個別プレゼントなど運用サービスへの通信は通しテスト内でローカル応答に置き換えた。

拠点の横位置検出には、自動切替バナーの前後・複製スライドも含まれる。幅360/412pxのホーム実タッチ・文書幅検査でスライド切替と操作を確認した。バナーの待機位置はゲームの不具合件数から除いた。
