# 進化時の全固有技カード配布

参照main: `d95364ee8656d3bf21f1eaa92d52491bb9bd09b4`。

通常進化53経路・特殊進化3経路。最小成立レベル（特殊はLv3）で29経路の初期装備カード配布に不足。初期装備選択と進化報酬を分離し、`moves` の全技を旧ID解決→統合ID変換→重複除去して各1枚付与する。装備条件、3枠、COST上限は配布対象を絞らない。通常・特殊両方の既存呼出しを置換し、図鑑初回登録とは独立に個体ごとに配布する。通常進化の無効・古い選択は成立前に拒否する。

既存装備の引き継ぎは従来の `ensureInstanceSkills` を維持。加入時の配布、セーブ構造・移行、技・能力・進化条件・素材量は変更せず、過去の進化への補填は行わない。装備可能な技や攻略法の追加制限なし。
