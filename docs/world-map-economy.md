# 世界地図化による収益影響の確認基準

## 現在の判定

世界地図は既存の `MAPS`、`HUNT_DIFFICULTIES`、`createHuntRequest`、単体戦／三つ巴／乱入の報酬関数を再利用しており、1戦ごとの経験値・コイン・素材・契約率を変更していない。遠征も従来どおり1勝ごとに進行する。

変化するのは、従来のランダム3候補から、プレイヤーが場所と成立する難易度を直接選べるようになる点である。このため、狙った通常モンスターや素材へ到達するまでの更新回数は減る。これは世界地図化の目的に含まれるが、特定報酬の時間当たり入手量は公開前の通しプレイで確認する。

## 維持したルール

- Easy / Normal / Hard / Extremeのレベル、報酬倍率、ターン条件
- 通常探索の三つ巴・乱入判定
- 単体戦・複数戦の報酬計算と契約判定
- 黄金郷の追加コインと、地図の出発時消費
- 遠征の必要勝利数と報酬
- エリシア、ネメシオン危機、偽竜、特殊入口は通常候補へ混入させない

## 公開前の比較手順

同じ初期パーティーと所持品で、旧版と開発版をそれぞれ通常探索10勝、Hard探索10勝行い、次を記録する。

1. 経過時間、候補更新／画面遷移回数
2. 獲得EXP、コイン、通常素材、上質素材
3. 契約提示数と成功数
4. 三つ巴／乱入の発生数
5. 遠征の進行数
6. 特定の通常モンスターを1回見つけるまでの時間

抽選のばらつきが大きいため、1回の10勝だけで数値調整を決めない。明確な異常がある場合だけ、既存報酬式ではなく入口頻度・候補構成のどちらが原因かを分けて修正する。
