- 勝利、敗北、撤退の結果パネルを追加し、経験値、コイン、ターン数、次の依頼を即時表示
- 三つ巴・乱入戦の2体分報酬と戦闘後契約を結果パネルへ接続
- 三つ巴戦で対象候補を発光表示し、敵画像の直接タップとキーボードで対象を選択可能に変更
