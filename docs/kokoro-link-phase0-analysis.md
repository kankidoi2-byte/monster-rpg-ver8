# ココロリンク Phase 0：実データ分析と実装判断

状態：Phase 0完了時点の技術判断  
対象：序章モンスター50体  
プレイヤー向け挙動：変更なし

## 1. Phase 0の目的

ココロリンクをUIから先に実装せず、現在のモンスターデータと戦闘計算を基に、低レアリティをリンク面で活躍させられる倍率と安全な計算構造を決める。

分析は `npm run analyze:kokoro-link` で再実行できる。自動検証は `npm run check:kokoro-link-analysis` で行う。

## 2. 現行戦闘システムから判明した制約

- 独立した基礎攻撃力ステータスは存在しない。
- 通常攻撃ダメージは、主に技威力、戦闘中攻撃倍率、属性相性、難易度、マップ補正、錬成個体補正から計算される。
- レベルで直接伸びる基礎値はHP。素早さとモンスター固有技の威力はレベルで増えない。
- レアリティはHP・素早さ・技威力の傾向だけでなく、技装備コスト上限にも影響する。
- したがって「控えの攻撃力を倍率変換して加算」という単一計算式は、現行データへそのまま適用できない。

## 3. レアリティ別基礎値

個体ごとの平均を同じ重みで集計した。

| レアリティ | 体数 | 平均Lv1 HP | 平均素早さ | 平均固有技威力 |
|---|---:|---:|---:|---:|
| ★1 | 10 | 102.00 | 68.20 | 26.40 |
| ★2 | 18 | 151.00 | 75.00 | 39.93 |
| ★3 | 13 | 212.69 | 86.00 | 68.06 |
| ★4 | 4 | 253.75 | 105.00 | 68.50 |
| ★5 | 5 | 360.00 | 92.20 | 81.73 |

★1と★5の差は、Lv1 HPで約3.53倍、平均固有技威力で約3.10倍、素早さで約1.35倍だった。能力ごとに差が大きく異なるため、全能力へ同じ割合を直接加算する方式は採用しない。

## 4. Phase 0提案倍率

| レアリティ | 提案倍率 |
|---|---:|
| ★1 | 3.5倍 |
| ★2 | 2.6倍 |
| ★3 | 1.9倍 |
| ★4 | 1.3倍 |
| ★5 | 1.0倍 |

この倍率はバトル中のモンスター本体へ直接掛ける値ではない。控えモンスターから算出するリンク指数へ掛ける値とする。

```text
HPリンク指数      ＝ 控えのLv反映HP × レアリティ倍率
速度リンク指数    ＝ 控えの素早さ × レアリティ倍率
攻勢リンク指数    ＝ 控えの平均固有技威力 × レアリティ倍率
```

### Lv1での倍率適用後指数

| レアリティ | HP指数 | 速度指数 | 攻勢指数 |
|---|---:|---:|---:|
| ★1 | 357.00 | 238.70 | 92.40 |
| ★2 | 392.60 | 195.00 | 103.82 |
| ★3 | 404.12 | 163.40 | 129.32 |
| ★4 | 329.88 | 136.50 | 89.05 |
| ★5 | 360.00 | 92.20 | 81.73 |

倍率適用後は、低レアリティが少なくとも一部のリンク分野で★5を上回る。特に★1は速度面、★3は攻勢面で強い。この結果は「★1は高倍率」「★3はリンク戦術の中核」「★5は直接戦闘向け」という設計思想と一致する。

## 5. レベル補正の比較結果

次の3方式をLv1・Lv5・Lv10で比較した。

1. レアリティ補正のみ
2. 低レベルほど倍率を上げる
3. 育成に応じて倍率をわずかに増やす

低レベル優遇方式では、★1の速度指数がLv1の286.44からLv10の211.25へ、攻勢指数が110.88から81.77へ低下した。現在の素早さと固有技威力はレベルで伸びないため、レベル補正だけが下がり、育てない方がリンク要員として強くなる。

### Phase 0判断

- MVPでは「低レベルほど倍率上昇」を採用しない。
- レアリティ倍率はレベルにかかわらず固定する。
- HPリンク指数だけは、既存のレベル成長が自然に反映される。
- 育成微増補正は将来候補とするが、初期実装には入れない。
- 低レベル個体を救済する必要が生じた場合も、育成後に弱くなる補正ではなく、必要経験値や編成コスト側で調整する。

## 6. Phase 1へ渡す計算契約

Phase 1では、リンク計算をUIや戦闘処理から独立した純粋関数として実装する。

### 入力

- 控え個体UID
- モンスターID
- レベル
- レアリティ
- HP
- 素早さ
- 固有技威力
- 属性

### 出力

- レアリティ倍率
- HPリンク指数
- 速度リンク指数
- 攻勢リンク指数
- 追加リンク能力を付与できるレアリティ帯
- 表示用の倍率・強化説明

### 必須制約

- ★5の追加リンク能力は常に「なし」。倍率は1.0。
- ★1～★3は追加リンク能力の対象。
- ★4の追加能力有無は未決定のままデータ上で切り替え可能にする。
- 指数を戦闘能力へ直接加算せず、能力ごとに別の転換率と上限を通す。
- 個体の装備技変更でリンク性能を極端に操作できないよう、攻勢指数は装備技ではなくモンスター固有技データを基準とする。
- 通常戦と三つ巴・乱入戦は同じリンク計算関数を利用する。

## 7. バトル値への変換方針

Phase 0では指数までを確定し、最終的な上昇量はPhase 1の自動テストで上限とともに決める。

有力な変換先は次の通り。

- HPリンク指数：最大HPの直接変更ではなく、一時バリアまたは被ダメージ軽減へ変換
- 速度リンク指数：素早さ補正へ変換。ただし先制が固定化しない上限を設ける
- 攻勢リンク指数：`pAtk`へ加える攻撃倍率へ変換。一撃必殺化を防ぐ上限を設ける

HPの最大値を戦闘途中に書き換えると、交代、回復、戦闘終了時の復元が複雑になる。初期実装では一時バリア方式が最も安全。

## 8. セーブ・編成に関する準備判断

- 通常パーティーは従来どおり最大3体とし、リンク専用の別枠は作らない。
- 現在戦闘中の1体を、同じパーティーの控え2体が支援する。
- リンク要員UIDをセーブへ追加する必要はなく、旧セーブ移行も不要。
- 候補は戦闘中の `partyBattle` から毎回算出する。
- 各控えは戦闘中1回までリンクでき、使用後も交代出撃できる。
- 戦闘不能の個体、現在戦闘中の個体、使用済み個体は候補から除外する。
- リンク要員はモンスターのみとし、キャラクターは現時点では対象外とする。

## 9. Phase 0で変更しないもの

- バトル画面
- パーティー編成画面
- セーブデータ形式
- 通常戦、三つ巴、乱入戦の挙動
- モンスターデータ
- 属性別リンク能力
- プレイヤー向けお知らせ

Phase 0は分析・テスト・技術判断のみであり、既存プレイヤーへの影響はない。

## 10. Phase 0結論

ココロリンクは現在のデータ構造でも実装可能。ただし、存在しない基礎攻撃力を前提にせず、HP・速度・攻勢の3指数を別々に計算して、安全な戦闘効果へ変換する必要がある。

初期倍率は★1＝3.5、★2＝2.6、★3＝1.9、★4＝1.3、★5＝1.0をPhase 1の基準値とする。低レベル優遇補正は育成逆転を起こすため、MVPでは不採用とする。

次の作業はPhase 1として、戦闘やUIから独立したココロリンク計算エンジンと、その上限検証を実装すること。
