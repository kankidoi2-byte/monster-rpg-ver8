# 草原マップストーリーの実装

原稿: https://docs.google.com/document/d/15fwtSLjgj4uSc8eiDIsRjOyOpMYOAlqXhYLxpI2dCIs

2026-10-12に調整した全11話を実装。契約者の15発言を含むセリフ・地の文は原稿からそのまま収録した。演出ノードは既存の草原背景と地の文で表現し、制作指示の文言はプレイヤーへ表示しない。

草原の詳細画面に独立した入口を追加。序章完了・正式スキップで第1話を解放し、前話の戦闘後会話を完了してから次話を解放する。各話1戦、第3・9話は三つ巴。通常探索の抽選・契約・素材・世界イベント・遠征・通常履歴の経路は通さない。

## 保存と互換性

既存キー `mb_v95c` を保持し、`mapStories.grassland_whose` を追加する。旧セーブでは `version:1, episodes:{}, resume:null` で初期化し、他マップや未知のフィールドを保持する。

初回/再戦の報酬・個体ごとの経験値・コイン・勝利数・戦闘後の再開位置は、既存トランザクションでまとめて保存する。失敗時はまとめて戻し、保存再試行へ案内する。報酬は実際の戦闘参加UIDにのみ付与し、勝利後の会話再開・読み返しでは重複付与しない。戦闘中断は同じ敵と参加UIDでHP満タン・ターン0から再挑戦する。遅延処理はattemptとプロフィールの識別を確認する。

## 原稿からの数値調整

第11話ボルタックスの攻撃補正だけを **1.10 → 0.75** に変更した。HP・レベル・素早さ・技・台本・報酬は維持する。初期値1.10では基準編成Aが100試行とも敗北し、0.75では85/100勝利となった。原稿の受入条件「基準編成Aの第10〜11話は70％以上」と、条件外ではストーリーの技/攻撃補正を先に調整する指定に従う。通常探索や種族マスターには適用しない。

現行の仲間は110技体系の初期装備を使用する。敵は原稿で指定された既存の固定技IDを戦闘用コピーへ設定し、均等抽選する。ストーリー敵の回復量は原稿の27HPを維持する。

## 検証

- `npm run check:map-story`: 全11話、原稿のID/HP/技、解放、各個体EXP4070/コイン1265、再読、再戦、撤退/敗北、実保存からの復元、保存失敗/再試行、古いattemptの無視。
- `NODE_PATH=<jsdom modules> node scripts/test-map-story-dom.mjs`: 本編HTMLと全スクリプトを読み込み、タイトル→ホーム→編成→草原→全11話の会話/戦闘/結果→草原への帰還を操作する。第1話は実際の攻撃で勝利し、その後は進行検証のためHPを0にして結果処理を呼ぶ。進化をキャンセルした後の入口も確認する。
- `node scripts/analyze-map-story-balance.mjs`: 本物の戦闘エンジンで各話100乱数種×2編成条件=2,200戦。Aは初回報酬だけで成長、Bは各戦Lv8固定。アイテム・進化・リンク・追加育成なし。行動方針と結果は同フォルダのJSONに記録する。
- 最終版はリポジトリ全体の `npm run check` に合格した（postcheckを含む）。

DOM検証はブラウザの描画/端末実機テストではない。320〜430px、横向き、文字200％での描画とAndroid/Chromebook操作は実機確認が必要。

既存の任意テスト `scripts/test-battle-journey-dom.mjs` は通常戦の敗北断定で失敗した。同じ失敗を変更前のmain（1a5d211）でも再現したため、今回の草原実装の回帰としては扱わず、既存テストの修正は含めていない。
