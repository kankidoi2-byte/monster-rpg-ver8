# 110技体系の共通戦闘処理

参照main: `9d62c8f`。採用数値はユーザー指定を正とし、旧技は旧IDの互換処理を保持する。

## 実装

- `s110_*` は single / multi の両エントリポイントから同じ `performSkill110Attack` と `resolveTacticalSkillEffects` を通る。敵対敵も同じ。技名分岐はない。
- `guard` は軽減率、`charge` はダメージ倍率。既存の一時状態スロットを利用し、真偽値の旧状態は45% / 1.20に解釈。新規効果は強い方だけを保存する。
- 複数回攻撃は総威力と1回分の乱数加算から総ダメージを求め、各打撃へ分割。集中・防御・リンク障壁/一撃軽減/回避は技全体について1回判定。途中KOで残りの打撃を止める。
- 条件付きダメージ倍率は攻撃直前HPで判定し、ダメージに掛ける。整数化した威力への倍率ではない。
- 全強化解除はダメージ後に攻撃強化、防御、水の盾、集中、ココロ障壁と防御型リンクの残り回数を解除。低級打ち消しは攻撃倍率が1超の場合のみ1へ戻す。負の補正は解除しない。
- 防御突破は防御/水の盾/リンク障壁/防御型リンク軽減を無視する。属性・攻撃倍率・難易度・マップ補正・回避・命中は維持。
- 吸収は実減少HP基準、反動は最大HP基準・切り捨て最低1・KO可能。新採用技の反動は旧リンク能力で無料化しない。命中低下によるミスでも使用後の反動を受ける。
- 回復式は採用値を基礎回復量として用い、既存マップ条件の回復半減などは共通 `adjustedBattleHealing` でその後に適用する。味方・敵とも同じ。
- 回復と反動は最後にHP範囲へクランプ。回復技は集中を消費しない。攻撃が外れても集中は消費する。
- 既存どおり交代時に攻撃倍率、状態異常、防御、集中、水の盾をリセット。戦闘開始/終了の既存リセットを利用し、新たなセーブフィールドを作らない。同時KOは既存の敵全滅先判定を維持。

## 担当者判断

- AIは現在レベルの合法初期装備を `defaultSkillIdsForMonster` で生成して選び、COST25を除く。回復はHP55%未満、強化/集中/防御は未到達時、解除は対象に効果がある時に選ぶ。
- 補助候補がある時の選択率60%、連続補助を禁止、1戦1敵あたり補助選択は計4回まで。その後攻撃へ固定する。これは回復・防御の無限反復防止のためのAI方針で、技の回数制限ではない。
- 多段攻撃の分割は総ダメージの商と余りを各打撃へ配る。1打目だけに追加乱数を積み上げない。

## 実行結果（2026-10-10）

- 619件の共通処理テスト成功。実110技それぞれを5方向で実行し、HP/攻撃/防御/集中/状態異常の一致を確認。
- 100ユニット×Lv1/10/50/100＝400ケースで敵の合法装備、攻撃手段、最強技の除外、30回選択しても補助4回以内・連続補助なしを確認。
- 通常攻撃コマンドも新処理を使用し、70%防御と1.30集中を正しく適用。防御突破でも回避は可能、突破した障壁の残量は削らない、ミスした反動でKO可能という境界ケースも成功。
- マップ回復半減、状態異常の部分解除、敵HP50%境界を含めて検証。
- `node scripts/test-skill110-battles.mjs`：通常戦、三つ巴、乱入、ネメシオン、滅亡の星ネメシオンを各2seed、計12戦。実ユニット/初期装備/レベル/HP/難易度で戦闘開始から勝敗まで実行。全戦2〜18ターンで終了。勝利・敗北、交代、報酬を通過。詳細は `skill110-battle-results.json`。
- 旧仕様互換：アルケミオン反動32ケース、通常回復420ケース、旧技戦闘1020比較、旧202技＋新110技のモーション定義、全429技/通常攻撃の接触・終了時刻検証も成功。
- 全条件/全編成の数学的終局性は証明していない。AIの補助連打は有限化済みだが、プレイヤーが自ら回復・補助だけを選び続ける場合まで強制終了させる仕様変更は加えていない。
- 432組合せの追加防御テスト成功：防御/水の盾/リンク一撃防御/水鏡のうち最大軽減のみ適用し、HP障壁は軽減後に消費。防御突破と単発/2連撃も全組合せで検証。突破時はリンク防御の残り回数やHP障壁を消費しない。
- 無料の通常攻撃コマンドは収集技110種類とは別の既存操作として維持するが、戦闘処理では同じ集中・防御仕様を使う。一時的な解決用配列だけを生成し、セーブへ新規IDを追加しない。
- 追加の実編成6戦：森属性ユニットに合法な毒攻撃・小回復・身構えるを装備し、HPに応じた回復と3ターンごとの防御を選択。合計で攻撃13回/回復86回/防御52回を実行し、通常敵・ネメシオン・滅亡の星すべて9〜40ターンで勝敗確定。攻撃のみの12戦と合わせて18戦。
- 勝利/敗北/撤退×単体/複数の6ケースで攻撃倍率・防御・集中・状態異常を戦闘終了時に初期化することを検証。HP・撃破帰属・報酬済みフラグは保持し、契約/結果画面へ引き継ぐ。
- 力の薬を実際に使用してから攻撃し、1.60上限を確認。外部の不正な倍率値も新共通処理の入口と倍率setterで0.65〜1.60へクランプする。
- ブラウザー用旧回帰は廃止済みIDを明示して旧処理を引き続き検証し、画面の所持・装備一覧は110技だけを期待するよう更新。応急治療の実画面検証ケースも追加。これらは構文検査済みだが、この実行環境ではブラウザー/HTTPサーバーを起動していないため実画面成功とは扱わない。

## 未解決：無制限回復による任意の長期化

合法なLv100グラスビート（最大HP1298）に大回復COST15/鉄壁の構えCOST7/威圧COST4を装備し、通常Lv5スライムと対戦。大回復のみを100ターン選ぶテストでは勝敗がつかず、終了時HP1266。回復は1回440、敵の基本攻撃は最大35であり、回数/MP制限がない採用仕様のままでは永続的な回復が可能。これはAI補助の有限化だけでは解決しない。

同じ構成で防御のみを選んだ場合は156ターンで敗北、威圧のみは67ターンで敗北。攻撃を混ぜる6戦は9〜40ターンで終了した。100ターンはテストの観測上限であり、本編へターン制限を実装していない。

大回復などの確定値は変更していない。完全な停滞禁止を求める場合は、回復のクールダウン、使用回数/資源、戦闘ターン上限など新しい設計判断が必要。この点は未解決としてレビュー用PRに明記する。
