旧説明は「付与確率%で相手を○○状態にする」のみ。新説明はそれを維持し、以下を追加する。

| 種類 | 追加内容 |
| --- | --- |
| 毒 | 3ターン継続し、各ターン終了時に最大HPの10%ダメージ（端数切り捨て、最低1ダメージ） |
| 麻痺 | 3回の行動まで継続し、行動時30%で行動不能（行動できた場合も残り回数を消費） |
| こんらん | 2～3回の行動まで継続し、行動時50%で通常行動、25%で行動不能、25%で自分を攻撃 |
| ねむり | 2回の行動まで継続し、行動時に行動不能 |

行動時の回数は各状態の判定時に消費する。ねむり判定は麻痺・こんらんより先、麻痺判定はこんらんより先に行われ、先行判定で行動不能になった場合は後続の状態判定を行わない。説明には各状態単独の基本効果を記載する。確率は技の基礎確率で、既存のリンクによる確率補正も変更しない。
