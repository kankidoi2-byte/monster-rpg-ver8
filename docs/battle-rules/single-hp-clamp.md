# 単体戦のHP減算時補正（2026-10-06）

調査版 `d0d67c85fcdb3ccc426c8774736d330302bd62e4`、実装開始main `70ef014f5c750ca0561a734b2a5620c8f8bec30e`。最新mainには同時KO修正が統合済みだが、対象8か所は未補正。

## 範囲

`doAttack` の通常攻撃、固定8HP反動、alchemy_recoil、追加攻撃の味方/敵双方を `Math.max(0, hp - damage)` に変更する。すでに補正済みの毒・こんらん・tacticalアクセサーや複数戦は変更しない。ダメージ・乱数・技データ・COST・相性・防御・盾・障壁・反動無効・吸収・発動条件・最大1回・同時KO・勝敗・報酬・契約・ID・保存形式は維持する。8番やネメシオン攻略変更を含めない。

`actualDamage = Math.min(dmg, Math.max(0, defenderHpBefore))` は維持。錬成反動はこの実ダメージ量の25%切り捨て、最低1。従来drainの計算上ダメージの半分、tacticalとリンク吸収の実ダメージ参照も維持する。計算上のダメージはHPを超えてもログ・表示イベントのdamageにそのまま渡す。補正するのは残存HPだけ。

画面の負数表示や負数保存は確認されておらず、既存の表示処理と最終updateで補正されていた一時的な内部不整合を修正する。プレイヤーが観測する仕様・表示変更がないため、AGENTS.mdの「other changes players cannot observe」に従い告知を追加しない。battle-rulesのキャッシュ識別子だけ更新する。
