# 正の威力を持つbuff/debuff技（2026-10-06）

対象は蒼竜の咆哮（42/竜/COST3）、呪いの視線（18/闇/COST2）、蝕月咆哮（46/竜/COST4）。技ID、データ定義、入手・装備条件、保存形式は維持する。

`doAttack`と`performMultiAttack`のbuff/debuff早期returnを威力0以下に限定。正の威力は既存の通常攻撃経路でダメージと演出を処理してから、buffなら使用者の攻撃倍率を+0.25（上限1.6）、debuffならその攻撃対象を-0.20（下限0.65）する。各1回。確率判定は追加しない。撃破・バリアでHPダメージ0でも、命中処理まで進んだ場合は適用する。既存の目くらましによるミスreturnでは追加効果も発生しない。

適用順の根拠：`docs/character-tactical-skills.md`の攻撃後効果仕様と、両経路の既存tactical追加効果処理（通常ダメージ→吸収→攻撃後効果）。強化によって同じ一撃の威力を増やさない。既存の補助buff/debuffは成功率・生存条件なしで適用していたため、新たな確率や撃破時の制限を導入しない。ネメシオンや強化解除・状態異常への対策は変更しない。

説明はこの3技だけ攻撃後の効果量・上限/下限を明記。正威力技の既存damage演出を利用し、複数戦の対象ログを攻撃対象へ合わせ、技選択の強化付き攻撃の対象説明を「自分と敵1体」に修正する。5つの変更JSにキャッシュ識別子を追加。

検証：`test-powered-modifiers.mjs`は修正前コミット77730b5の実処理と現行処理を比較。192ケース（単体/三つ巴/実際の乱入切替、味方→敵/敵→味方/敵→敵、上限下限、0威力、防御/水盾、回復半減、属性、ミス、バリア、撃破帰属）を通し、144ケースで旧ダメージ0を再現。正威力のダメージ/HP演出は効果なし対照と一致。表示・描画はVMでは代替される。

既存HP負数テストは全ソースの完全一致制約を8減算のクランプ保持検査に変更し、50攻撃・31旧負数再現・24勝敗/保存比較は維持。新ブラウザテストはCIで実行し、24攻撃の実モーション対象、ログ、技装備、図鑑の実表示（モンスター詳細は出現・入手方法）、タイトル/ホーム/編成/狩猟/戦闘、保存/再読み込みを検証する。ローカルではChromium実行ファイルがなく実行不可。Android/Chromebook実機は未検証。

モンスター図鑑の現行詳細は出現・入手方法を表示し、技カードは表示しない。図鑑共通の技説明生成`renderUnitSkillList`はVMで3技を照合する。ブラウザでは各モンスターの実際の詳細表示を確認し、存在しない技カードを成功扱いにしない。
