# 技カード影絵22種類の組込み

採用された影絵22種類を全110技の共通カード描画に割り当てる。技図鑑、技装備、技ガチャ演出・結果・拡大表示で共用する。対応は `js/skill-card-art.js`、原本の照合情報と全技一覧は `docs/skill-silhouettes-20261101.json` に記録。

- 1技につき1種類。威圧と弱体化は別に扱う。
- 属性は背景と属性表記、級は従来の枠・文字で表示。追加効果による画像差分は増やさない。
- 表示用分類は既存の form タグ・装備条件と独立。技ID・性能・取得処理・セーブ形式は変更しない。
- 原本は採用素材ZIPに保管。配信画像は512×512、白地の輝度を透過へ変換し、白黒境界の紙ノイズを除去して16段階のアンチエイリアスを付けた lossless WebP。向き・構図は維持。
- 22枚合計281,020バイト（約274 KiB）。個別の属性やレアリティ画像は不要。
- ファイル名と読込バージョンを新しくして既存キャッシュとの混在を防ぐ。

検証：全110技の対応・素材存在・サイズ予算・通常／コンパクト表示・描画時のデータ不変性を自動検証。既存のガチャブラウザ検証で22枚のWebPデコードと全110カードの参照を確認する。

Android／Chromebook実機では未検証。公開後は同一ソース版の検証・Pages配信結果を確認する。
