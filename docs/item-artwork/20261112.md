# Six item illustrations (2026-11-12)

Owner-supplied PNGs added to the game's Drive art folder on 2026-11-11 were inspected individually and matched by their exact names to existing items:

| G-ICHOR.png | g_ichor | g_ichor_art_v1.webp |

All runtime files are in `images/items/`. Converted with Pillow to 768×768 WebP, quality 88, method 6, keeping the source aspect ratio and transparency. No cropping, recoloring, or generated replacement art. Combined size: 696,974 bytes; each asset is below the existing 300 KiB budget. Existing files and references are preserved.

Only `ITEM_IMG` entries and a player-facing notice change runtime behavior. Existing item IDs, names, prices, availability, effects, quantities, save schema, and `mb_v95c` remain unchanged. Common item visuals pick up the illustrations in the unlocked item encyclopedia, shop, alchemy materials, and gift rewards. Unobtained encyclopedia entries remain hidden. Text-only controls remain text-only.
