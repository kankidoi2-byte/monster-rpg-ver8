# ココロリンク Phase 4-2：★2リンク能力

更新日：2026-08-26
状態：実装・自動検証済み、統合前

## 1. 実装範囲

Phase 4-0で確定した★2「属性・状態異常」10種を通常戦と三つ巴戦へ接続した。基礎リンク成立直後に対象敵へ一度だけ成功判定を行い、不発でも基礎リンクと控えの使用済み状態は残る。

## 3. 対象と成功判定

- 通常戦では現在の敵を対象とする。
- 三つ巴戦では★2リンクを選んだ後、敵A・敵Bから対象を指定する。
- 通常敵への成功率は70％。
- `bossClass`を持つボスへの成功率は35％。
- `kokoroLinkStatusImmune`が明示された敵には追加能力だけが無効になる。
- 判定は一度だけで、失敗時の再抽選は行わない。

## 4. 重複・持続処理

- 攻撃低下と素早さ低下は同じ項目を加算せず、強い効果を残して長い残り時間を採用する。
- 火傷とリンク毒はそれぞれ最大HP5％をターン終了時に与える。
- 通常技の毒が有効な場合は、より強い通常毒を優先する。
- 麻痺・こんらん・ねむりは同時保持せず、新しく成功した1種類へ置き換える。
- 行動遅延は次の行動順決定時に1回消費する。
- 目くらましは敵の攻撃技ごとに命中80％で判定する。

## 5. 表示

候補カードと発動中カードに「★2リンク能力」の名称、効果、成功・不発を表示する。敵の状態欄には能力名と残りターンを表示し、成功率、不発、継続ダメージ、効果終了をバトルログへ表示する。
