# ココロリンク Phase 4-0：追加能力の共通ルール

状態：設計・実装基盤完了
対象：★1～★3の追加リンク能力、属性マトリクス、発動・重複・耐性・上限
プレイヤー向け挙動：★1能力はPhase 4-1、★2能力はPhase 4-2で接続済み。★3は未接続

## 1. 目的

追加能力を個体ごとの固有能力にせず、原則として「レアリティ帯 × 主属性」で決める。低レアリティの編成価値を高めつつ、特定の高レア能力だけが必須になる環境を防ぐ。

- ★1：単純で強い数値強化
- ★2：属性効果・状態異常
- ★3：回復、解除、行動補助などの戦術支援
- ★4・★5：追加能力なし。基礎リンクだけを使用する
- 複属性：モンスターデータの先頭にある主属性だけを参照する
- 無属性：全分野を扱えるが、各専門属性の最大効果は超えない

個体名やレベル、錬成補正、装備技から能力を決めない。同じレアリティ・主属性なら同じ追加能力になる。

## 2. 能力マトリクス

| 主属性 | ★1：数値強化 | ★2：属性・状態異常 | ★3：戦術支援 |
|---|---|---|---|
| 無 | 万能強化（各専門より低い複合強化） | 原初の弱化 | 原初選択（小回復・解除・コスト軽減） |
| 火 | 攻撃強化 | 火傷 | 反動無効 |
| 水 | 障壁強化 | 鈍足 | 技コスト軽減 |
| 森 | 継続回復 | 毒 | 即時回復 |
| 雷 | 素早さ強化 | 麻痺 | 次行動の優先化 |
| 風 | 回避 | 行動遅延 | 無消費交代 |
| 光 | 初撃防護 | 目くらまし | 状態異常解除 |
| 闇 | 吸収 | こんらん | 敵の強化解除 |
| 星 | 運命強化 | ねむり | 予知 |
| 竜 | 技威力強化 | 攻撃低下 | 耐性貫通 |

これは能力の所属を確定する表であり、Phase 4-1～4-3で既存戦闘処理へ一系統ずつ接続する。新しい個体限定能力は、この表の能力で役割を表現できないことを確認してから別途検討する。

### 能力名の確定内容

- 万能強化：攻撃・追加障壁・素早さを各5％。専門属性の15％を超えない。
- 原初の弱化：敵の攻撃・素早さを各10％、2ターン低下。
- 原初選択：最大HP10％回復、状態異常解除、次の技コスト1軽減から1つを選ぶ。
- 火：攻撃15％、火傷は最大HP5％×2ターン、反動無効は次の反動1回。
- 水：追加障壁15％、鈍足は素早さ20％低下×2ターン、コスト軽減は次の技1回だけ1軽減。
- 森：最大HP5％×2ターンの継続回復、毒は最大HP5％×2ターン、即時回復は最大HP20％。
- 雷：素早さ15％、麻痺は1ターン、行動優先は次の行動1回。
- 風：次の攻撃を20％で回避、行動遅延は次の行動順を最後へ送る、無消費交代は次の手動交代1回。
- 光：次の被ダメージ25％軽減、目くらましは命中20％低下×2ターン、解除は味方の状態異常をすべて解除。
- 闇：次の与ダメージの20％を吸収（最大HP10％まで）、こんらんは1ターン、強化解除は敵の解除可能な強化をすべて解除。
- 星：次の確率判定を15ポイント有利化、ねむりは1ターン、予知は敵の次の行動を1ターン表示。
- 竜：次の技威力15％、攻撃20％低下×2ターン、次の攻撃が耐性・軽減を20％分貫通。

## 3. 発動タイミングと対象

- 基礎リンク成立直後に、追加能力を1回だけ解決する。
- 発動は通常行動を消費しない。
- 支援効果の対象は、リンクを受けた戦闘中モンスターとする。
- 妨害効果の対象は、通常戦では現在の敵、複数敵戦では選択中の敵とする。ランダム対象にはしない。
- 交代後も持続効果は発動対象UIDへ残り、別個体へ移らない。
- 発動条件を満たさない場合でも、基礎リンクは成立する。追加能力だけが不発になる。
- 不発時の再抽選はなく、控えの1戦闘1回を消費する。

## 4. 成功判定とボス耐性

味方への回復・解除・強化・行動補助は、対象が有効なら100％成功する。敵への状態異常・弱体化は次の一度だけ判定する。

```text
通常敵への成功率 ＝ 70％
ボスへの成功率   ＝ 70％ × ボス耐性50％ ＝ 35％
```

- ボス判定は討伐依頼などの明示的な戦闘フラグを使い、名前やレアリティから推測しない。
- 麻痺・ねむりなどの行動不能は成功しても最大1ターン。
- 状態異常の通常上限は2ターン。
- 成功率上昇能力を将来追加しても、最終成功率は100％を超えない。
- 完全耐性を持つ戦闘では、基礎リンクは成立し、該当する追加能力だけが無効になる。

## 5. 重複ルール

- 基礎リンクの障壁・攻撃・素早さと追加能力は別枠として共存する。
- 1体が受けられる追加リンク能力は、既存の「1対象につきリンク1つ」に合わせて1つまで。
- 同じ効果カテゴリは加算しない。効果量は強い方、残り時間は長い方を採用する。
- 行動不能系（麻痺・ねむり・こんらん）は同時に複数保持しない。
- 毒・火傷などの継続ダメージは状態ごとに1つまで。同じ状態の再付与は威力を重ねず、残り時間だけを上限内で更新する。
- 回復・解除など即時効果は重複判定の対象外だが、1回のリンク発動につき一度だけ解決する。
- 敵味方の既存技による同系統効果とも同じ上限を共有し、リンクだけで上限を回避できないようにする。

## 6. 数値上限

追加能力は基礎リンクの10～35％とは別枠だが、次の上限を超えない。

| 効果 | 1回の上限 |
|---|---:|
| 追加攻撃強化 | 対象の基準値の15％ |
| 追加障壁 | 対象最大HPの15％ |
| 追加素早さ強化 | 対象素早さの15％ |
| 即時回復 | 対象最大HPの20％ |
| 継続回復 | 1ターン最大HPの5％、最大2ターン |
| 毒・火傷 | 1ターン敵最大HPの5％、最大2ターン |
| 行動不能 | 最大1ターン |
| その他の状態異常・弱体 | 最大2ターン、弱体率最大20％ |
| 回避 | 次の攻撃1回、20％ |
| 初撃軽減 | 次の攻撃1回、25％ |
| 吸収 | 与ダメージの20％、回復量は最大HPの10％まで |
| 確率補正 | 次の判定1回、15ポイント |
| 耐性貫通 | 次の攻撃1回、20％ |
| 技コスト軽減 | 最大1、最低コスト1 |

★1の専門強化を基礎リンクへ加えた場合、該当項目だけ最大50％相当になる。無属性の万能強化は複数項目を強化できる代わりに、各項目を専門属性の15％未満にする。

## 7. 技コスト軽減の保留条件

現行の技コストは、戦闘前の装備上限であり、戦闘中に消費する資源ではない。このため水★3と無★3のコスト軽減枠は能力マトリクスに保持するが、現時点では戦闘効果へ接続しない。

実装する前に、戦闘内コスト、最低コスト1、軽減対象は次の1回だけ、戦闘終了時リセット、という条件を満たす消費資源を別途設計する。装備済み技のコスト表示だけを下げる見かけ上の効果にはしない。

## 8. 実装境界

Phase 4-0では `KOKORO_LINK_ABILITY_RULES` と `buildKokoroLinkAbilityPlan(profile)` を追加する。これは能力所属と共通制約を返す純粋な設計基盤で、戦闘状態を変更しない。

- セーブデータ変更なし
- 現行の基礎リンク効果変更なし
- プレイヤー向け表示変更なし
- お知らせ追加なし（まだ遊べる挙動が増えていないため）

Phase 4-1で、★1の数値強化をこの上限に従って通常戦・三つ巴戦へ接続した。実装内容は [Phase 4-1：★1リンク能力](./kokoro-link-phase4-1-power-abilities.md) を参照する。

Phase 4-2で、★2の属性・状態異常能力を成功判定とボス耐性込みで通常戦・三つ巴戦へ接続した。実装内容は [Phase 4-2：★2リンク能力](./kokoro-link-phase4-2-status-abilities.md) を参照する。

次はPhase 4-3で、★3の戦術支援能力を実戦へ接続する。
