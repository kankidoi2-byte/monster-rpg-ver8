# ココロリンク Phase 4-3：★3リンク能力

更新日：2026-08-26
状態：実装・自動検証・公開完了

## 1. 実装範囲

Phase 4-0で確定した★3「戦術支援」10種を通常戦と三つ巴戦へ接続した。味方への支援は有効な対象へ100％発動し、基礎リンクと同じく通常行動を消費しない。

## 2. 能力一覧

| 主属性 | 能力 | 実戦効果 |
|---|---|---|
| 無 | 原初選択 | 最大HP10％回復、状態異常解除から1つ選択。技コスト軽減は保留 |
| 火 | 炎身不動 | 次の反動ダメージを1回無効 |
| 水 | 水脈節約 | 戦闘内コスト実装まで保留 |
| 森 | 森命活性 | 最大HP20％を即時回復 |
| 雷 | 雷迅先行 | 次の行動を最優先 |
| 風 | 風渡り交代 | 次の手動交代を行動消費なしで実行 |
| 光 | 光明浄化 | 毒・麻痺・こんらん・ねむりをすべて解除 |
| 闇 | 闇蝕解除 | 対象敵の攻撃強化、防御、フレアチャージ、水の盾を解除 |
| 星 | 星見予知 | 対象敵の次の技を表示し、予知した技を次行動に使用させる |
| 竜 | 竜牙貫通 | 次の攻撃が属性耐性・防御・水の盾の軽減を20％分貫通 |

## 3. 選択と対象

- 無属性はリンク成立後に「小回復」「浄化」から選ぶ。未選択のまま閉じてもリンク画面から再開できる。
- 風属性は発動直後またはリンク画面から、生存している控えを選んで無消費交代できる。
- 闇・星属性は三つ巴戦で敵A・敵Bから対象を指定する。通常戦では現在の敵を対象とする。
- その他の能力はリンクを受けた戦闘中モンスターへ適用する。

## 4. 消費と持続

- 反動無効、行動優先、無消費交代、行動予知、耐性貫通は条件を満たした1回だけ消費する。
- 回復・解除はリンク成立時または選択確定時に一度だけ解決する。
- 敵強化解除は能力発動時点の解除可能な強化だけを対象とする。
- 予知した技は次の行動順決定時に消費し、表示も終了する。
- 耐性貫通は威力を持つ次の攻撃で消費し、補助技では消費しない。

## 5. 技コスト軽減の保留

現行の技コストは戦闘前の装備上限であり、戦闘中に消費する資源ではない。そのため水属性と無属性の技コスト軽減は候補・発動中表示に「保留中」と明記し、見かけのコストだけを変更しない。

## 6. 表示

リンク候補カードと発動中カードへ「★3リンク能力」の名称と効果を表示する。選択、回復量、解除結果、反動無効、無消費交代、予知した技、耐性貫通はバトルログへ記録する。
