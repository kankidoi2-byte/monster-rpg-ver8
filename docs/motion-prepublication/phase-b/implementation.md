## 実装した内容
- グランボルモーグv18を通常のBATTLE_IDLE_MEDIAへ追加。評価branch内の登録数は2/50、残48。一般公開やmain反映は行わない。
- 動画・静止画は既存の検査済みGit blobを通常assets経路でも参照。同一バイトで再変換・Base64送信なし。QA用原本は履歴・比較のため維持する。
- 各個体に任意のcanvas位置x/y（0〜1）・scale（0.1〜1）を指定できる共通経路。動画と静止代替に同じ設定を使い、破棄時に設定を解除。グランは既に計測した中央下寄せ/倍率1/味方反転をそのまま移す。既存ボルモーグは旧設定を維持。
- sourceBoundsは全編検査からの占有範囲の記録。現実装はcanvas containであり、このboundsを使った全身拡大・解剖学的な足点合わせ・影位置調整の完成ではない。未確認値は作らない。最終素材調整はC/Dで残る。
- IntersectionObserverが使える場合、最初の可視通知までは動画srcを付けず静止表示。可視率15%以上で再生、2%以下が250ms続けば停止。境界付近の行き来で連続再生成しない。同じvideoと時刻を保持。
- 画面非表示、別画面、低モーション、pagehide等の停止理由を優先。古い監視通知・タイマーは所有権と世代で無効化。離脱/交代/終了で監視解除。非対応ブラウザは既存の画面/文書単位停止を維持。
- 通常の再生予算は1。検証用の最大3設定は維持するが、全端末/長時間性能合格や通常3体解禁とはしない。
- 隔離レビューは候補registry注入から通常registry使用へ変更。保存隔離を維持し、検証済み配置を共通CSSへ移す。プレイヤー向け告知とcache queryを更新。
