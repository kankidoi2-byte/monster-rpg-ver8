# Phase C 第11便 — オルカ3体

2026-09-30 JST。オルカーナ、オルカストリーム、オルカアビスの採用版v3を通常戦闘・確認一覧へ登録。39/50、残り11体。

制作ZIP内の全身MP4と採用別添を全バイトで照合。既存render.pyのtransparent=TrueからVP9 CRF18で派生動画を出力。原画・既存補完画像・rig・rendererを変更しない。v1/v2の不採用動作へ戻さない。新たな画像生成や色キー処理は行わない。

960×960、30fps、8秒、全240フレームを順次処理。原本MP4との数値比較、6時点の元背景への再合成、0秒/8秒の元RGBA一致、派生WebM全フレームの透過・外接矩形・端接触を検査。再合成は元opaque描画と完全一致。異なる圧縮形式間のRGB完全一致は主張しない。

静止代替は検査済みWebM先頭フレームからWebP化。オルカーナとオルカストリームは味方反転、オルカアビスは敵反転。浮遊する採用動作を維持し、最終足場・配置・Galaxy負荷はPhase D/E/Fで受け入れる。DOM/media模擬検査は実端末受入を代替しない。

動画は作業ブランチに保存。本人限定確認サイトは固定コミット・サイズ・SHA-256付きmanifestでR2配信し、動画をarchiveに再同梱しない。非公開Drive IDやサイト運用ID/URLを公開証跡に含めない。
